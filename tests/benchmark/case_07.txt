Git 版本控制是现代软件开发的基础工具。核心概念：工作区（Working Directory）、暂存区（Staging Area）和仓库（Repository）。基本工作流：git add 将修改加入暂存区，git commit 将暂存内容提交到本地仓库，git push 推送到远程仓库。分支管理是关键特性：创建分支（git branch）、切换分支（git checkout/switch）、合并分支（git merge/rebase）。常见协作模式：GitHub Flow（feature branch → PR → merge）、Git Flow（develop/release/hotfix 多分支）和 Trunk-Based Development。冲突解决是必备技能：git status 查看冲突文件、手动编辑冲突标记、git add 标记已解决。高级技巧包括 interactive rebase、cherry-pick、stash 和 bisect。
