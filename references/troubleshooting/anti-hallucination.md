# 防幻觉验证系统

> 从 mindmap-generator (Dicklesworthstone) 的 5 层防幻觉架构提炼。将 AI 生成的内容与源文档做交叉验证。

## 为什么需要？

AI 生成思维导图时的典型幻觉：
- 凭空编造源文档中不存在的关系
- 过度概括导致关键细节丢失
- 错误合并相似但不同的概念
- 添加看似合理但未提及的"常识"节点

## 五层验证体系

```
层级 1: 内容存在性 → 每个节点是否在源文档中显式提及或逻辑可推导？
    ↓
层级 2: 置信度评分 → 高置信度(直接引用) vs 低置信度(推理引申)
    ↓
层级 3: 结构保真度 → 层级关系是否符合源文档的逻辑结构？
    ↓
层级 4: 语义去重 → 是否有冗余/重复节点（不同措辞表达同一概念）？
    ↓
层级 5: 优雅降级 → 验证失败时，宁可删除节点而非保留错误信息
```

## 层级 1：内容存在性验证

### 检查清单

对每个生成节点，执行以下检查：

| 检查 | 判断标准 | 处理 |
|------|---------|------|
| 显式提及 | 源文档中能找到相同或相近表述 | ✅ 通过 |
| 逻辑可推导 | 源文档中 A→B，推断 B→C 但 C 未提及 | ⚠️ 标记为「推断」 |
| 无根据 | 源文档中完全无迹可寻 | ❌ 删除节点 |

### 操作流程

```
AI 生成导图后 → 逐节点回溯源文档：
  1. 用关键词搜索源文档定位
  2. 确认匹配程度
  3. 标注「显式/推断/无根据」
  4. 删除所有「无根据」节点
```

## 层级 2：置信度评分

```yaml
每个节点的元数据（可嵌入 Markdown 注释）:

<!-- confidence: high | source: 第3段第2句 -->
### 节点的核心论点

<!-- confidence: medium | source: 从第5-7段推断 -->
### 节点的重要推论

<!-- confidence: low | source: 仅标题提及 -->
### 节点的边缘信息
```

### 处置策略

| 置信度 | 保留 | 标注 | 示例场景 |
|--------|:----:|:----:|---------|
| high | ✅ | 可选 | 源文档直接陈述的核心概念 |
| medium | ✅ | **必须** | 从多处综合推断的结论 |
| low | ⚠️ | **必须** | 只在一个边缘位置简单提及 |

## 层级 3：结构保真度

### 检查父子关系

```
源文档结构:              生成的导图:
  1. 定义                  # 概念
    a) 类型A                ## 类型A
    b) 类型B                ## 类型B
  2. 应用                    ## 应用场景
    a) 场景A                  ### 工业场景
    b) 场景B                  ### 错误归类 ← 实际属于类型B的特征

验证: "工业场景"和"场景A"是同一回事吗？如果不是 → 结构错误
```

### 结构自检清单

1. 每个子节点的内容是否**真的**属于其父节点的范畴？
2. 同级节点之间的**并列关系**是否在源文档中有依据？
3. 嵌套深度是否与源文档的**论述层次**一致？

## 层级 4：语义去重

| 方法 | 原理 | 工具 |
|------|------|------|
| 文本相似度 | 字面重叠率 | `difflib.SequenceMatcher` |
| 模糊匹配 | 容忍错字/简繁 | `fuzzywuzzy` |
| 语义相似度 | 不同措辞表达相同含义 | LLM 二次判定 |
| 层级冗余 | 父节点与子节点说同一件事 | 规则检查 |

## 层级 5：优雅降级

```
验证失败时的降级策略:

节点完全无依据 → 删除
节点置信度低 + 无兄弟节点 → 保留但标注
节点结构有误 → 调整父级而非删除
父节点被删 → 子节点提升到祖父级（如果子节点有效）
```

### 关键原则

> **宁可导图稀疏，不可包含虚假信息。**

## 防幻觉提示词模板

在 AI 提示词中嵌入防幻觉指令：

```
生成规则：
1. 每个 ## 和 ### 节点的内容必须能在原文中找到对应语句
2. 如果某个概念只在原文中提及一次且未展开，不要为其创建独立分支
3. 不要添加你的常识补充——只反映原文的内容
4. 如果原文对某话题只说了半句话，导图中也只保留半句话的信息量
5. 层级不超过原文的论述深度——原文三层则导图不超过三层

输出后自查：
- 逐个节点在原文中定位
- 删掉定位失败的节点
- 对推断类节点加 [推断] 标记
```
