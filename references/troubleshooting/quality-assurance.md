# 质量自检 — AI 生成内容的交叉校验

> AI 生成完笔记或导图后，别直接收工。花 5 分钟做交叉校验，能抓出 90% 的遗漏和编造。

## 概述

来自 OCR→AI笔记管道的实战经验：AI 在整理知识时可能出现两类典型问题：
- **MISSING（遗漏）**：源材料有的内容，AI 输出中没出现
- **HALLUCINATION（幻觉）**：AI 输出了源材料中没有的内容

这套自检流程帮你快速定位这两种问题。

## 3 步自检法

### Step 1：清单对比（2 分钟）

对着源材料清单，逐条勾一下 AI 输出中是否覆盖：

```
源材料清单              AI 输出覆盖？
├── 概念A的定义          ✅ 已覆盖
├── 概念B的3个特征       ⚠️ 只提了2个 → MISSING
├── 方法C的5个步骤       ✅ 已覆盖
├── 案例D的数据          ❌ 完全没提 → MISSING
└── 注意事项E            ✅ 已覆盖但加了原文没有的建议 → HALLUCINATION
```

### Step 2：关键数据核验（1 分钟）

专门检查数字类内容：

| 检查项 | 方法 |
|--------|------|
| 步骤数量 | AI 说「5 个步骤」→ 源材料里真的是 5 个吗？ |
| 数字/比例 | AI 说的数据能追溯到源材料的具体位置吗？ |
| 专有名词 | 人名、产品名、方法论名称拼写对吗？ |
| 时间节点 | 日期和先后顺序有没有颠倒了？ |

### Step 3：结构完整性（2 分钟）

- 源材料是三层结构 → AI 输出是不是也三层？有没有层级丢失？
- 同级内容是否平衡？（某个分支只有 1 条，其余分支 5 条 → 可能遗漏）
- 有没有用「等」「及其他」「……」模糊带过的地方？

## 常见问题模式

| 模式 | 描述 | 高频场景 |
|------|------|---------|
| **头重脚轻** | 前面的内容很详细，后面越来越简略 | 长文档处理、多文件合并 |
| **合并丢失** | 两个相似概念合并时，丢掉了其中一个的独有特征 | 多来源知识整理 |
| **编造过渡** | AI 为了「行文流畅」添加了原文没有的连接词和因果关系 | 方法论类内容 |
| **数字漂移** | 「3 个要点」变成了「几个要点」→ 「若干要点」 | 多次改写后 |
| **术语替换** | 用近义词替换原文术语，改变了专业含义 | 专业领域内容 |

## 对思维导图特别适用

思维导图的节点式结构让 MISSING 更容易发现：

- 每个一级分支 = 源材料的一个大板块 → 数量对得上吗？
- 每个叶子节点 = 一个具体知识点 → 有没有只剩标题没内容的空分支？
- 同级分支的逻辑关系（并列/递进/因果）→ AI 有没有搞混？

## 行动指南

1. 生成后用 Step 1-3 过一遍，标记 MISSING 和 HALLUCINATION
2. MISSING 的 → 把源材料的对应段落重新喂给 AI：「这部分漏了，请补充」
3. HALLUCINATION 的 → 删除并标注「原文无此内容」
4. 如果 MISSING > 20% 且 HALLUCINATION > 5 处 → 考虑换个 AI 工具或重新组织提示词

## 进阶：反幻觉校验（Reality Check）

> 来自 [mindmap-generator](https://github.com/Dicklesworthstone/mindmap-generator) 的核心模式：在 AI 生成时主动验证，而非事后检查。

### 在提示词中嵌入校验指令

在通道 A 的提示词模板中追加这段话，让 AI 自我校验：

```
生成完成后，请执行反幻觉校验：
1. 逐一检查每个节点的事实声明，确认在原文中有对应出处
2. 如果某个声明找不到原文支持，标注为 [推测] 或删除
3. 确认所有数字、日期、人名与原文一致
4. 确认没有将不同段落的信息错误合并
```

### 语义去重检查

AI 可能在多个分支中重复相同概念。追加校验指令：

```
检查是否存在语义重复：
- 不同分支中有相似含义的节点 → 合并到最合适的位置
- 同一概念用了不同表述 → 统一术语
- 父节点和子节点含义相同 → 删除子节点或重新定位
```

### 文档类型适配

不同文档类型需要不同的校验重点：

| 文档类型 | 校验重点 |
|---------|---------|
| 法律文书 | 条款编号、定义精确性、适用范围 |
| 技术文档 | 参数值、API 名称、版本号、配置项 |
| 学术论文 | 引用来源、数据值、方法论名称 |
| 商业报告 | 财务数字、百分比、时间节点、责任人 |
| 叙事文本 | 事件顺序、人物名称、因果关系 |
