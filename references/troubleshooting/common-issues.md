# 常见问题排查

> 遇到问题先查这里，90% 的情况都能解决。

## Markdown 导入 XMind

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 导入后中文乱码 | 文件编码不是 UTF-8 | 用记事本重新另存为，编码选 UTF-8 |
| XMind 提示「无法识别文件格式」 | 文件后缀不是 `.md` | 确认文件名为 `xxx.md`，不是 `xxx.md.txt`（在资源管理器中开启「显示文件扩展名」） |
| 导入后层级全乱了 | AI 输出的 Markdown 不规范 | 检查 AI 输出：`#` 后面要有空格，子级缩进和符号要正确 |
| 导入后没有内容 | 文件为空或全是注释 | 检查 `.md` 文件内容，确认有实际内容 |

## AI 输出问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| AI 输出大量解释文字 | 提示词缺少「只输出代码」 | 在提示词末尾加上「只输出 Markdown/Mermaid 代码，不要任何额外解释」 |
| Markdown 层级不对 | 提示词不够明确 | 加上「使用 # 作为中心主题，## 作为一级分支，### 作为二级分支」 |
| 内容太泛/空洞 | 提示词缺少约束 | 加上「每个节点给出具体、可直接使用的建议」和「层级不超过 4 层」 |
| 输出不是中文 | AI 默认用英文回复 | 提示词开头加上「请用中文回复」或直接用中文提示词 |
| AI 说「无法识别图片中的文字」 | 图片质量太低 | 重新拍摄/扫描，确保清晰、光线均匀、分辨率 ≥ 800px |

## Mermaid 流程图

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| Mermaid 渲染不出来 | 语法错误 | 复制到 https://mermaid.live 在线调试，左侧会显示错误位置 |
| 导入 draw.io 后布局错乱 | Mermaid 语义被误解 | 在 draw.io 中手动调整节点位置（拖拽即可） |
| 决策菱形没有「是/否」标签 | 连线标签没有写 | 语法：`A{判断} -->|是| B[操作]` 和 `A -->|否| C[其他]` |
| 节点太多（>30）挤在一起 | Mermaid 自动布局限制 | 拆分为多个子图，或用 `subgraph` 分组 |

## 文件保存问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| Windows 记事本没有 UTF-8 选项 | 旧版 Windows | 下载 Notepad++ 或用 VS Code 保存 |
| 保存后是 `xxx.md.txt` | Windows 隐藏了已知扩展名 | 资源管理器 → 查看 → 勾选「文件扩展名」 |
| 复制粘贴后换行丢失 | 用了 Ctrl+A 全选 | 使用 AI 界面的「复制」按钮，不要手动全选 |

## 思维导图设计问题

| 问题 | 原因 | 解决方法 |
|------|------|---------|
| 导图太拥挤/看不懂 | 节点太多或层级太深 | 参考 [[../methodology/seven-elements]]：每节点 ≤1 关键词，层级 ≤4 |
| 不知道从哪开始 | 缺乏结构化思维 | 参考 [[../methodology/five-star-heart]]：先结构化→再逻辑化 |
| 画完了但没有洞察 | 只是罗列信息，没有分析 | 参考 [[../methodology/diverge-converge]]：加上收敛阶段 |
| 导图好看但不实用 | 过度美化，内容空虚 | 回头看内容本身：每个节点是否回答了「那又怎样？」 |

## 软件选择问题

| 问题 | 建议 |
|------|------|
| 思维导图该用什么软件？ | **XMind**。免费版够用，导入 Markdown 最方便 |
| 流程图该用什么软件？ | **draw.io**。免费、功能全、支持 Mermaid 导入 |
| 什么时候用 Visio？ | 公司要求/Office 集成/特别复杂的工程图 |
| 在线工具 vs 桌面版？ | 偶尔用 → 在线版；常用 → 桌面版 |

参考 [[../software/cross-tool-mapping]] 查看完整工具对比。
