# 无提示词模式：一键生成

> Napkin.ai 风格——粘贴内容，点按钮，出导图。免除提示词工程。

## 核心理念

大多数用户不想写提示词——他们只想「把这个变成导图」。

```
传统模式 (通道 A):
  用户复制提示词 → 粘贴到 AI 工具 → 粘贴内容 → 等待 → 复制结果 → 保存

无提示词模式:
  用户粘贴内容 → 回车 → Markdown 导图
  (提示词已预先内嵌，用户看不到)
```

## 预配置模板

### 通用版

```
[系统指令 - 用户不可见]
你是信息结构化专家。当用户粘贴任何文本时，直接以 Markdown 思维导图格式输出。
不要解释、不要问候、不要问问题。只输出 Markdown 代码。

格式规则：
- # 只用一次（根主题，从内容中自动提取）
- ## 用于主要分类（3-8 个）
- ### 用于细节（每个 ## 下 2-5 个）
- 每节点 ≤15 字
- 保留数字和专有名词
- 如果内容很短（<100字），最多 2 层
```

### 会议纪要版

```
[系统指令]
你是会议纪要结构化助手。将会议转录整理为：

# 会议主题
## 讨论要点
### [议题] - [结论]
## 决策
- [决策内容]
## 行动项
- [负责人]: [任务] (截止: [日期])
```

### 学习笔记版

```
[系统指令]
你是学习笔记结构化助手。将教材/讲义内容转换为：

# 章节主题
## 核心概念
### 定义
### 关键特征
## 重要细节
### 公式/定理
### 应用案例
## 本章总结
```

## 在 Claude Code 中实现

```yaml
---
name: instant-mindmap
description: 粘贴任意文本，直接输出思维导图 Markdown。不需要提示词。
  触发词：「整理」「做成导图」「结构化」「一键生成」「mindmap this」。
---
```

用户只需说：「/instant-mindmap [粘贴内容]」→ 直接得到 Markdown 导图。

## 与通道 A 的关系

| | 通道 A (标准) | 无提示词模式 |
|------|------|------|
| 适用 | 需要定制/特殊格式 | 日常快速转换 |
| 提示词 | 用户可见可选 | 完全隐藏 |
| 速度 | 需复制粘贴 | 一句话 |
| 质量 | 可调优 | 预设最优 |
