# 对话实时转思维导图

> 从 mcp-chat-visualizer 提炼。将正在进行的对话自动生成为思维导图。

## 使用场景

| 场景 | 触发方式 |
|------|---------|
| 长对话总结 | 对话中途/结束时「把这段对话整理成导图」 |
| 头脑风暴记录 | 脑暴过程中实时捕捉→结构化 |
| 会议纪要 | 会议结束后自动生成结构化的纪要导图 |
| 代码审查归档 | 审查结束后生成审查要点的思维导图 |

## 安装

```bash
# 安装对话可视化 MCP 服务器
claude mcp add chat-visualizer -- npx mcp-chat-visualizer
```

无需 API Key、无外部调用——纯 LLM 生成层级 JSON。

## 在我们的管道中集成

### 流程 A：手动触发

```
① 对话进行中或结束时
② 用户：「把这段对话整理成思维导图」
③ Skill 自动走通道 A：提取核心主题→层级化→输出 Markdown
④ 保存为 .md → 导入 XMind 或直接生成
```

### 流程 B：自动触发（通过 MCP）

```
① 对话时长超过阈值（如 30 轮）→ 自动提示
② 或对话中出现关键信号词（「总结一下」「整理一下」）→ 自动提取
③ chat-visualizer MCP 生成层级 JSON
④ 转为 Markdown → multi_export.py 并行导出多种格式
```

## AI 提示词模板

```
你是一位对话总结专家。请将以下对话记录整理为思维导图结构。

要求：
1. 以对话的核心主题为 # 根节点
2. 以每个关键话题为 ## 一级分支
3. 每个话题下的讨论要点为 ### 二级分支
4. 具体的结论/行动项为 - 叶子节点
5. 每个节点 ≤15 字
6. 只输出 Markdown 代码

对话记录：
[粘贴对话内容]
```

## 输出示例

```markdown
# Q4 营销策略讨论
## 渠道表现
### 社交媒体
- 小红书 ROI +35%
- 抖音转化率下降
### 搜索广告
- 品牌词 CVR 提升
## 预算调整
### 增投
- 小红书 +20%
- KOL 合作
### 减投
- 展示广告 -15%
## 行动项
### 本周
- 更新小红书素材
### 下周
- AB测试新落地页
```
