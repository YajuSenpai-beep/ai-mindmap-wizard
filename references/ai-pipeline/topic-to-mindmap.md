# 只有主题 → 思维导图 扩展流程

> 只有一个模糊的想法或主题？AI 可以帮你扩展成完整的思维导图框架。

## 适用场景

- 「我想做一个关于 XX 的思维导图，但不知道从哪开始」
- 「给我一个项目管理知识体系的完整框架」
- 「帮我梳理一下职业规划应该考虑哪些方面」

## 流程

```
你的主题 → AI 扩展为结构化大纲(Markdown) → 保存 .md → XMind 导入 → 你在上面修改补充
```

## 提示词模板

```
请为主题「[你的主题]」生成一份结构化的思维导图大纲，以 Markdown 格式输出。

要求：
- 使用 # 作为中心主题，## 作为主要分支，### 作为子分支，- 作为细节节点
- 覆盖该主题的所有关键方面，做到全面且有逻辑层次
- 层级不超过 4 层
- 每个节点的文字简洁明了，不超过 15 字
- 只输出 Markdown 代码，不要任何额外解释
```

## 变体：指定视角

如果你需要从特定角度分析，在主题后加上视角：

```
请从「[视角]」的角度，为主题「[主题]」生成思维导图大纲。

例如：
- 请从「初学者快速上手」的角度，为主题「Python 数据分析」生成...
- 请从「成本控制和风险防范」的角度，为主题「开一家咖啡店」生成...
- 请从「管理者而非执行者」的角度，为主题「团队 OKR 制定」生成...
```

## 变体：指定结构

如果你想要特定结构，直接在提示词中描述：

```
请为主题「2025 年个人年度计划」生成思维导图，按以下结构组织：
- 职业发展
- 学习成长
- 健康生活
- 人际关系
- 财务状况
每个大类下面再细分目标和行动步骤。
```

## 关键建议

> **AI 生成的是起点，不是终点。**
>
> AI 给出的框架是帮你快速从「空白页」到「有东西可改」。真正有价值的部分是你在此基础上：
> - 删除不相关的分支
> - 添加 AI 不知道的个性化信息
> - 根据实际情况调整优先级
>
> ——这是 AI 工具和五星心法中「放射化→简单化」的完美结合。

## 后续步骤

AI 生成大纲后：
1. 导入 XMind（参考 [文本→导图流程](text-to-mindmap.md)）
2. 用 [发散-收敛](../methodology/diverge-converge.md) 的方法，做你自己的发散补充
3. 用 [7要素](../methodology/seven-elements.md) 的规则优化节点关键词
4. 最终导图应该融合了 AI 的广度 + 你的深度

**输入**：「我想做一个关于 6S 管理的思维导图」

**AI 生成的典型大纲**：
```

### 6S 的价值

### 清扫 (Seiso)
### 清洁 (Seiketsu)
### 素养 (Shitsuke)
### 安全 (Safety)

### 全面推广

### 执行不持久
## 评估与持续改进
### 考核标准

```
