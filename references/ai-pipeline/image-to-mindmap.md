# 图片 → 思维导图 重建流程

> 看到一张好的思维导图想「拿来用」？AI 可以识别图片中的结构，生成可编辑版本。

## 适用场景

- 看到别人画的思维导图，想二次编辑
- 书籍/讲义中的手绘导图，想数字化
- 会议白板上的导图，想整理存档

## 流程

```
思维导图图片 → 上传到 AI → AI 识别结构并输出 Markdown → 保存 .md → XMind 导入 → 可编辑
```

## 操作步骤

### 第一步：获取清晰的图片

- 截图或拍照尽量**正面、平整、光线均匀**
- 手绘导图用扫描 App（如 CamScanner）比拍照效果好
- 分辨率不要太低（至少 800px 宽）

### 第二步：上传 AI 并生成 Markdown

在任意支持图片上传的 AI 工具中，上传图片并使用以下提示词：

```
请根据这张图片中的思维导图，识别其结构和文字内容，整理成 Markdown 格式输出。

要求：
- 保持原始层级结构，使用 # ## ### - 表示
- 文字内容与图片保持一致
- 如果图片中有模糊不清的文字，用 [?] 标注
- 只输出 Markdown 代码，不要任何额外解释
```

### 第三步：保存和导入

与文本流程相同：复制 → 粘贴到记事本 → 另存为 UTF-8 编码的 `.md` 文件 → XMind 导入。

详细步骤参考 [文本→导图流程](text-to-mindmap.md) 第三、四步。

## 注意事项

| 问题 | 解决 |
|------|------|
| AI 识别不完整 | 图片太模糊 → 重新拍摄/扫描；颜色对比低 → 增强对比度后再上传 |
| 层级结构不对 | 在提示词中补一句「请注意区分一级分支和二级分支」 |
| 中文 OCR 错误 | 用支持中文更好的 AI 工具（KIMI 和 DeepSeek 的中文 OCR 较好） |
| 手写字体识别差 | 打印体识别效果远好于手写体；手写导图建议重新打字后再导 |

## 提升 OCR 识别率的技巧

### 拍照/扫描优化

| 问题 | 解决 |
|------|------|
| 倾斜/透视变形 | 用扫描 App（CamScanner/Adobe Scan）代替相机 |
| 光线不均匀 | 避免阴影和反光，自然光下平拍 |
| 彩色背景干扰 | 转为灰度图再上传（画图/Preview 即可转换） |
| 分辨率太低 | 至少 1200px 宽；PDF 扫描建议 200dpi 以上 |
| 文字模糊 | 拍摄时手稳，或使用三脚架/支架 |

### 图片预处理（进阶）

如果 AI 识别效果不佳，可以用工具预处理后再上传：

```
预处理策略（按效果从简到繁）：
  灰度化    → 去除彩色干扰
  对比度+50% → 文字和背景分离
  锐化      → 增强边缘
  中值滤波   → 去除噪点
  直方图均衡 → 改善过亮/过暗区域
```

Windows 画图支持基本的对比度和亮度调整；Mac Preview 支持灰度转换。如需批量处理，推荐 ImageMagick 命令行工具。

## PDF 处理策略

PDF 中的思维导图可能是文字型（可直接提取）也可能是图片型（需要 OCR）：

| PDF 类型 | 识别方式 | 效果 |
|----------|---------|------|
| **文字型 PDF**（可选中文字） | 直接复制文字 → 手工整理 Markdown | 最佳，无需 OCR |
| **混合型 PDF**（部分文字+部分图片） | 文字部分复制 + 图片部分截图上传 AI | 较好 |
| **扫描型 PDF**（全是图片） | 截图每一页 → 上传 AI 识别 | 取决于扫描质量 |

> **判断方法**：在 PDF 阅读器中尝试选中文字。能选中 = 文字型；不能选中 = 扫描型。

### 扫描型 PDF 的处理

1. 在 PDF 阅读器中导出为图片（或用截图工具逐页截图）
2. 确保导出分辨率 ≥ 200dpi
3. 逐页上传 AI，使用图片重建提示词
4. 如果页数超过 10 页，建议用 OCR 工具（如 Tesseract）先批量提取文字再上传 AI 整理

## 替代方案

如果 AI 识别效果不理想：
1. 看着图片，自己手打一份 Markdown 大纲（10 分钟 vs 1 小时重画）
2. 用 [五星心法](../methodology/five-star-heart.md) 的方法，自己重新梳理一张新导图
3. 在 XMind 中对照图片手动绘制（图片放左侧，XMind 放右侧）
