# 应用场景 — 思维导图实战模板

> 同样的方法论，在不同场景有不同的用法。

## 概述

思维导图可以应用于学习、职业规划、时间管理、演讲准备、活动组织等场景。每个场景有推荐的导图结构和操作流程。

## 场景一：读书/学习笔记

**目标**：把一本书或一篇文章变成一张能「一目了然」的导图。

**推荐结构**：
```
# 书名/文章标题
## 核心观点（这本书最重要的 3-5 个论点）
## 关键概念（术语 + 定义）
## 论证过程（论点 → 证据 → 案例）
## 个人启发（与我何干？可以用在哪里？）
```

**操作流程**：
1. 先通读，标记关键段落（不要边读边画）
2. 用 [发散-收敛](diverge-converge.md) 第一阶段：把记住的所有东西倒出来
3. 翻书查漏补缺，补充遗漏
4. 用 [7要素](seven-elements.md) 规则做最终整理

## 场景二：职业规划

**目标**：看清自己的位置、可能的方向、下一步行动。

**推荐结构**：
```
# 职业规划
## 现状分析（技能/经验/资源/兴趣）
## 可能方向（每个方向：机会/风险/匹配度）
## 3 年目标（SMART 原则）
## 下一步行动（3 个月内要做的 3 件事）
```

**关键方法论**：
- 使用 [五星心法](five-star-heart.md) 中的放射化：先列出所有可能方向，不做评判
- 用 SMART 原则（Specific / Measurable / Attainable / Relevant / Time-bound）评估目标
- 最终导图应该能回答：「我下周一开始做什么？」

## 场景三：时间管理

**目标**：用导图可视化时间分配，找到优化空间。

**推荐结构**：
```
# 时间管理
## 时间去向（本周实际时间分配）
## 重要-紧急矩阵
  ### 重要且紧急（立刻做）
  ### 重要不紧急（每天做一点）
  ### 紧急不重要（委托）
  ### 不重要不紧急（删除）
## 理想分配（目标状态）
## 改变行动（从哪开始调整）
```

## 场景四：演讲/汇报准备

**目标**：用一张导图支撑一场有逻辑、不忘词的演讲。

**推荐结构**：
```
# 演讲主题
## 开场（钩子：故事/数据/问题）
## 核心论点 1 → 证据/案例
## 核心论点 2 → 证据/案例
## 核心论点 3 → 证据/案例
## 结尾（总结 + 行动呼吁）
```

**关键技巧**：
- 每个一级分支 = 演讲的一个段落
- 用关键词做记忆锚点，不是逐字稿
- 练习时只看导图，不看稿子

## 场景五：活动组织

**目标**：用导图做全局规划，确保不遗漏。

**推荐结构**：
```
# 活动名称
## 目标与定位（为什么办/给谁办）
## 时间与场地（含备选方案）
## 人员分工（谁负责什么/截止时间）
## 流程安排（开始→环节1→环节2→...→结束）
## 物料清单（需要准备的物品）
## 预算（收入/支出/应急储备）
## 风险预案（什么可能出错/应对方案）
```

## 行动指南

1. 确定场景 → 使用对应的推荐结构
2. 先用 [发散-收敛](diverge-converge.md) 填内容
3. 用 [7要素](seven-elements.md) 规范美化
4. 如果需要生成实际文件，转到 AI 管道（[文本→导图流程](../ai-pipeline/text-to-mindmap.md)）
