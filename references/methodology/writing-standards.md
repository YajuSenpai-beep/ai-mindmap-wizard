# 写作规范 — AI 笔记生成质量标准

> 不只是「写出来」，而是要「写到位」。这些规范适用于让 AI 生成结构化笔记、思维导图内容或知识整理。

## 概述

从大量知识整理实战中提炼的 5 条写作原则 + 6 步处理流程 + 5 条禁止事项。无论是你自己写还是让 AI 生成，这套规范能确保输出质量。

## 5 条写作原则

### 1. 金字塔结构
- **先总后分**：每篇笔记 / 每张导图开头用 2-3 句话概括核心观点
- **层级清晰**：用 `# ## ### ####` 组织，不超过 4 级
- **逻辑递进**：按「是什么 → 为什么 → 怎么做」展开

> 这与 [五星心法](five-star-heart.md) 中的「结构化+逻辑化」完全对应。

### 2. 信息密度
- **逐条提取**：原文中的文字、框架、步骤不遗漏任何可操作知识点
- **去重合并**：同一知识点在多处出现时，合并为最完整版本
- **数字精确**：保留步骤编号、数据、比例、时间节点

### 3. 可执行性
- 方法论后附具体操作示例或话术模板
- 步骤类用有序列表，检查项用无序列表
- 能用表格对比的不用段落

### 4. 润色标准
- 原文口语化/碎片化 → 整理为书面语但保留原意
- 模糊概念用括号补充说明或举例
- 去掉营销夸张用语（「必看」「惊天」「炸裂」），保留实质内容
- 中英文术语首次出现标注对应关系

### 5. 格式规范
- 文件名：`{序号}_{主题名}.md`
- 正文不写「大家好」「欢迎阅读」等开场白，直接进入主题
- 代码块展示话术模板、SOP 流程
- 引用块 `>` 标注原文关键句

## 6 步处理流程

```
① 扫描 → 列出所有源文件，建立全局清单
② 阅读 → 逐文件读取内容（OCR 文本 / 原始笔记 / 图片描述）
③ 提取 → 将碎片知识点汇总为结构化大纲
④ 撰写 → 按金字塔结构写出完整笔记/导图
⑤ 检查 → 对比源文件清单，确认没有遗漏知识点
⑥ 润色 → 通读一遍，优化表达流畅度
```

## 5 条禁止事项

| ❌ 禁止 | ✅ 应该 |
|---------|--------|
| 跳过任何源文件不看 | 每个文件都过一遍，即使标记为「无新增内容」 |
| 用自己的理解替换原文方法论 | 可补充解释，但不改变原意 |
| 写「内容详见图片」— 知识必须完整呈现在文本中 | 把图片中的关键信息提取为文字 |
| 遗漏步骤中的任何一步 | 原始有几个步骤就保留几个步骤 |
| 编造原文没有的数据、公式、人名 | 不确定的用 `[待确认]` 标注 |

## 场景适配

### 用于思维导图

将写作规范映射到 [7要素](seven-elements.md)：
- 金字塔结构 = 中心主题 + 层级分支
- 信息密度 = 每节点 1 个关键词，≤15 字
- 可执行性 = 叶子节点为具体行动
- 禁止事项 = 不遗漏分支，不编造内容

### 用于 AI 生成

在给 AI 的提示词中加入规范引用（参考 [提示词模板库](../ai-pipeline/prompt-templates.md)）：

```
请遵循以下写作规范：
1. 金字塔结构：先总后分，层级不超过4级
2. 信息密度：逐条提取，去重合并，数字精确
3. 可执行性：方法论后附操作示例
4. 禁止：不编造数据，不跳过文件，不写开场白
```
