# 发散-收敛循环 — 创造性思维实操

> 先放后收：发散产生选项，收敛找到答案。

## 概述

思维导图用于创造性思维时，不是一次画完的。标准流程是一个「发散 → 收敛 → 再发散 → 再收敛」的循环。这个循环直接对应五星心法中的「放射化 → 简单化」。

## 三阶段循环

### 第一阶段：清空障碍（发散）

```
目标：把脑中所有想法倒出来，不评判、不筛选
```

- 画一张「混乱版」思维导图，没有任何限制
- 写出所有想法，包括「看起来蠢的」「不相关的」
- **禁止自我审查**：这个阶段没有「错」的分支
- 中心主题甚至可以是一个问题句

### 第二阶段：精准挖掘（收敛 → 再发散）

```
目标：从混沌中找到火花，然后深入挖掘
```

1. 回顾第一阶段的导图，圈出 3-5 个「火花」（让你兴奋/意外的节点）
2. 对每个火花，单开一张子导图，深入追问：
   - 为什么这个重要？
   - 它和什么相关？
   - 如果放大它，会怎样？
3. 这是「收敛选择 → 再次发散」的嵌套循环

### 第三阶段：系统筹划（最终收敛）

```
目标：将挖掘结果整理成结构化、可执行的导图
```

1. 扔掉第二阶段中所有不再相关的分支
2. 重新组织逻辑结构：并列 / 递进 / 因果 / 时间顺序
3. 应用 7 要素规则：精简关键词、加颜色区分、加关键插图
4. 最后问：这张图能不能让一个不熟悉主题的人看懂？

## 发散思维 6 法则

在发散阶段，以下技巧可以打破思维框架：

| 法则 | 操作 | 示例 |
|------|------|------|
| **量大于质** | 设定目标：至少 20 个分支 | 「这个问题的 20 个可能原因」 |
| **延迟判断** | 写的时候不做任何评价 | 哪怕写「外星人干涉」也先留着 |
| **嫁接联想** | 随机引入一个无关概念强制关联 | 「如果把产品当成一家餐厅来设计？」 |
| **角色切换** | 用不同身份视角思考 | 「乔布斯会怎么看？一个孩子会怎么看？」 |
| **反向思考** | 思考相反方向 | 「如何让用户体验更差？」→ 反向得到优化方向 |
| **极端推演** | 推到最极端的情况 | 「如果预算无限/为零？」「如果时间压缩到 1 天？」 |

## 行动指南

1. **有想法但不知道怎么开展的**：直接走第一阶段，先画一张混乱导图
2. **有初步方案想深化的**：跳到第二阶段，挑火花深入挖掘
3. **方案基本成型**：走第三阶段，用 7 要素规则做最终整理
