# 思维导图 7 要素

> 4 个基础要素是画任何导图都需要的；3 个特殊要素按目的选用。

## 概述

思维导图的绘制由 7 个要素组成。基础要素决定导图的结构完整性，特殊要素决定导图的表现力和记忆效果。

## 4 个基础要素（每张导图必备）

| 要素 | 说明 | 规则 |
|------|------|------|
| **中心图** | 整张导图的核心主题图像 | 位置：正中央；大小：约 1/9 页面（拳头大小）；颜色：≥3 种；避免荧光黄 |
| **布局结构** | 分支的排列方式 | 放射状（最常用）/ 树状 / 鱼骨状；分支间留白均匀；同级分支角度一致 |
| **关键词** | 每个节点上的文字 | 每节点 1 个关键词；≤8 字；用名词/动词，不用完整句子 |
| **逻辑线条** | 连接节点、表达关系的线 | 由粗到细（近中心粗，远端细）；同级同色；交叉越少越好 |

## 3 个特殊要素（按目的选用）

| 要素 | 何时用 | 规则 |
|------|--------|------|
| **插图** | 需要强化记忆、引起注意的关键节点 | 简单图标即可，不要求绘画能力；每个一级分支 ≤2 个插图 |
| **颜色** | 区分不同分支、标记优先级 | 同一分支同色系；不同分支不同色；≤5 种主色；红色留给最重要的 |
| **关联信息** | 不同分支间有逻辑联系 | 用虚线箭头连接；标注关联说明（≤5 字） |

## 要素使用指南

```
每张导图 = 中心图 + 布局结构 + 关键词 + 逻辑线条（必备）
           + 颜色（强烈推荐）
           + 插图（按需）
           + 关联信息（偶用）
```

## 常见误区

| 误区 | 纠正 |
|------|------|
| 中心图要画得很好看 | 不需要。简单几何图形 + 文字即可，重点是「有图」而非「画得好」 |
| 关键词写成完整句子 | 导图是思维索引，不是文章。1 个关键词 = 1 个记忆锚点 |
| 所有分支都加插图 | 插图多了反而分散注意力。只在关键处使用 |
| 颜色越多越好 | ≤5 色。超过 5 色失去区分意义，变成噪音 |
