# 五星心法 — 思维导图的核心方法论

> 思维导图不是画画，是思维的结构化呈现。

## 概述

五星心法将思维导图分解为五个递进层次，从底层逻辑到终极呈现，形成完整的「思维可视化」操作系统。

## 五层金字塔

```
                    ┌──────────────┐
                    │  ⑤ 图示化     │  ← 终极层：用图像/颜色/图标强化记忆
                    ├──────────────┤
                    │  ④ 简单化     │  ← 进化层：提取核心关键词
                    │  ③ 放射化     │
                    ├──────────────┤
                    │  ② 逻辑化     │  ← 基础层：支撑所有内容的两条腿
                    │  ① 结构化     │
                    └──────────────┘
```

### 基础层（地基）

| 层次 | 含义 | 核心操作 |
|------|------|---------|
| **① 结构化** | 将零散信息组织成层次分明的框架 | 确定中心主题 → 分大类 → 分子类 → 用 `#` `##` `###` 构建层级 |
| **② 逻辑化** | 建立节点间的逻辑关系 | 区分并列/递进/因果/对比关系，用线条和顺序表达逻辑 |

> 结构化 + 逻辑化 = 思维导图的「两条腿」，缺一不可。

### 进化层（升华）

| 层次 | 含义 | 核心操作 |
|------|------|---------|
| **③ 放射化** | 从中心向外发散，打开多维思考 | 自由联想、不设限制、每个分支独立发展 |
| **④ 简单化** | 提取核心关键词，剔除冗余 | 每个节点 ≤ 1 个关键词、≤ 8 个字、能删就删 |

> 放射化是「放」，简单化是「收」——先放后收，才是完整的思考循环。

### 终极层（呈现）

| 层次 | 含义 | 核心操作 |
|------|------|---------|
| **⑤ 图示化** | 用视觉元素强化理解和记忆 | 中心图（1/9 页面，≥3 色）、图标标记、颜色编码、关联箭头 |

## "思-维-导-图" 四字拆解

| 字 | 含义 | 对应心法层 |
|----|------|-----------|
| **思** | 思考的过程本身 | 结构化 + 逻辑化 |
| **维** | 打开多维、发散性思维 | 放射化 |
| **导** | 逻辑排序和信息引导 | 逻辑化 + 简单化 |
| **图** | 让思维可视化 | 图示化 |

## 行动指南

1. **拿到任何主题，先问**：中心主题是什么？→ 一级分支是什么关系？（并列/递进/因果）→ 每个分支能再拆吗？
2. **画完之后检查**：节点能否再删？逻辑是否通顺？有没有用图标/颜色区分重点？
3. **心法不是公式**：五星是框架，具体几层、几个分支取决于内容本身。
