# Tufte 数据可视化原则

> 从 Edward Tufte 三本经典著作 + tufte-claude-skill 提炼。将「图表应该怎么画」固化为可执行的原则。

## 为什么需要？

CRAP 四原则（对比/重复/对齐/亲密性）是**通用设计**原则。Tufte 原则专门针对**数据可视化**——让图表传递信息效率最大化。

## 十条核心原则

### 1. 显示数据
图表的核心目的是展示数据，不是装饰。每一个像素应该服务于数据传达。

### 2. 最大化数据墨水比
```
数据墨水比 = 数据墨水 / 总墨水

数据墨水 = 实际展示数据数字的部分
非数据墨水 = 网格线、背景色、装饰边框、3D 效果、渐变

目标：最大化数据墨水，最小化非数据墨水
```

**反例 → 正例**：

| ❌ | ✅ |
|----|----|
| 3D 柱形图（每个柱子有两面是装饰） | 平面柱形图 |
| 带渐变色背景的图表 | 纯白背景+灰细网格线 |
| 粗边框 + 深色表格线 | 浅灰细线或无网格线 |

### 3. 删除非数据墨水
逐项审查图表的每个视觉元素：
- 这个网格线可以去掉吗？→ 可以（用颜色编码替代）
- 这个边框可以淡化吗？→ 可以（从黑→浅灰）
- 这个 3D 效果增加了什么信息？→ 零信息（删除）

### 4. 图形完整性
图表的视觉比例必须等于数据的数字比例。

```
❌ 条形图：数值 10 的条高是数值 5 的 3 倍 → 视觉欺骗
✅ 条形图：比例严格等于 10:5 = 2:1

❌ 折线图Y轴不是从0开始 → 趋势被放大
✅ 如果截断Y轴，必须标记截断符号
```

### 5. 避免图表垃圾
| 垃圾类型 | 示例 | 替代 |
|---------|------|------|
| moiré 振动 | 密集斜线填充 | 纯色或微弱纹理 |
| 网格线过密 | 每 5 像素一条线 | 每 20 像素一条，浅灰 |
| 自提的图例 | 每根柱子自带标签+还有图例 | 直接标注柱子 |
| 不必要的 3D | 饼图 3D 倾斜 | 平面饼图或条形图 |

### 6. 鼓励眼睛比较
数据应该在**同一视觉区域内并排比较**，而非分页。

```
❌ 两个图表分在两页：「请比较图3和图4」
✅ 两组数据在同一图中并列：「请看对比」
```

### 7. 提供多层级阅读
好的图表支持三种阅读深度层级：
1. **一眼扫读**：标题+最粗的线=核心结论
2. **快速阅读**：坐标轴标签+数据标注=关键数字
3. **仔细研究**：网格线+细微标注=精确数值

### 8. 上下文与叙事
裸数据不是图表——图表必须告诉读者**为什么这个数据重要**。
- 标题应该是陈述句而非标签（"Q3 营收增长 15%" 而非 "Q3 营收"）
- 标注关键变化点（"此处是新产品上线节点"）

### 9. 颜色的克制使用
- 默认用灰度+单一高亮色——**不是所有东西都需要彩色**
- 彩色仅用于标记异常点、强调关键数据系列
- 避免使用超过 5 种颜色（人类短期记忆只能同时追踪约 4 种颜色）

### 10. 小倍数 (Small Multiples)
对于多组可比数据，用**相同设计的小图表阵列**而非一张复杂大图。

```
❌ 一图塞 10 条折线，颜色各异 → 无法阅读
✅ 10 个小图，每个一条折线，相同坐标轴 → 一眼比较
```

## 与 Mermaid 配色系统的关系

我们已有的 7 色 classDef 系统对齐 Tufte 原则：
- `classDef` 颜色语义化 → Tufte 的「颜色克制」
- 去除了默认的粗网格线背景 → Tufte 的「删除非数据墨水」
- 单色系+一高亮 → Tufte 的「灰度+单一高亮」

## 与通用设计原则的分工

| | CRAP (我们的 PPT) | Tufte |
|------|------|------|
| 领域 | 幻灯片设计 | 数据可视化 |
| 关注 | 视觉布局、信息层级 | 数据准确性、信息密度 |
| 核心 | 对比/重复/对齐/亲密性 | 数据墨水比/图形完整性/多层级阅读 |
| 何时用 | 所有视觉材料 | 图表和可视化 |
