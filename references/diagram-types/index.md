## 按受众速查

| 受众 | 适合的图表 | 原因 |
|------|-----------|------|
| 管理层/决策者 | SWOT、商业画布、仪表图、甘特图 | 需要宏观视角和决策支撑 |
| 技术团队 | ER图、UML、架构图、拓扑图、电路图 | 需要精确的技术规格 |
| 业务/运营团队 | 业务流程图、组织结构图、鱼骨图 | 需要流程和责任清晰 |
| 客户/外部 | 思维导图、时间线、比较图 | 需要直观易懂 |
| 全员/培训 | 思维导图、流程图、组织结构图 | 需要快速理解和记忆 |

## 不知道怎么选？回答三个问题

1. **目的是什么？** 梳理思路 → 思维导图 / 展示关系 → 结构图 / 分析决策 → 分析工具 / 规划执行 → 项目管理
2. **给谁看？** 管理层 → 宏观 / 技术 → 精确 / 客户 → 直观
3. **有多复杂？** 简单（≤10节点）→ 思维导图 / 中等 → 流程图 / 复杂 → 专业图表

回答后仍不确定？直接描述你手头的任务，我来推荐。
