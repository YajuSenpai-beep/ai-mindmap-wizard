# 项目管理图

> 什么时候做什么？谁做？——规划时间、任务和资源。

## 适用场景

- 项目排期和进度跟踪
- 展示里程碑和时间节点
- 任务分解和依赖关系管理
- 工程进度规划

## 图表类型对比

| 类型 | 用途 | 关键特征 |
|------|------|---------|
| **甘特图** | 任务排期和时间可视化 | 横轴=时间，纵轴=任务，条形=工期 |
| **项目流程图** | 项目整体流程和阶段 | 阶段节点、决策门、交付物 |
| **时间线/轴** | 展示事件的时间顺序 | 水平或垂直时间轴、关键事件标记 |
| **双代号网络图** | 工程任务的依赖关系和关键路径 | 节点=事件，箭头=任务，标注工期 |

## 通用绘制流程

1. **列出所有任务**：把项目拆成可执行的子任务
2. **确定依赖关系**：哪些任务必须在其他任务之后？
3. **估算时间**：每个任务需要多久？谁来做？
4. **标记里程碑**：哪些节点是必须按时完成的关键点？
5. **找关键路径**：从开始到结束，哪条路径最长？（决定了项目的最短工期）

## 各图表要点

### 甘特图
- 横轴 = 时间（天/周/月），纵轴 = 任务列表
- 每条任务 = 一个横条，从开始日期到结束日期
- 用不同颜色区分：已完成 / 进行中 / 未开始 / 延期
- 标记里程碑（用菱形图标）和依赖箭头
- 在 draw.io 中有甘特图模板，也支持用 Mermaid 生成（`gantt` 语法）

### 时间线/轴
- 适合展示 5-30 个关键事件
- 事件过多时分组（如按年/月分组）
- 每个事件：日期 + 标题 + 一句话说明
- 可在 XMind 中用「时间轴」布局直接绘制

### 项目流程图
- 关注阶段（Phase）而非单个任务
- 每个阶段的输出物是什么？
- 阶段间的决策门：达到什么条件才能进入下一阶段？

### 双代号网络图
- 工程管理专用，非工程场景不推荐
- 节点编号、任务名称、工期标注要齐全
- 关键路径用加粗/红色标出

## 自查

1. 每个任务都有明确的负责人和截止日期？
2. 依赖关系是否清晰（A 完成 → B 才能开始）？
3. 关键路径是否正确识别？
