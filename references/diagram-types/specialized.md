# 专业制图

> 空间怎么布局？视觉效果怎么设计？——面向特定领域的专业图表。

## 适用场景

- 办公室/店铺/住宅的空间规划和布局
- 消防安全设计
- 服务器机柜和设备布局
- UI/产品原型草图
- 故事板/海报/日历等创意设计

## 图表类型对比

| 类型 | 用途 | 关键特征 |
|------|------|---------|
| **建筑平面图** | 室内空间布局和尺寸 | 墙体、门窗、家具、标注尺寸 |
| **消防图** | 消防设备和逃生路线 | 灭火器/消防栓/逃生箭头/集合点 |
| **办公室布局图** | 办公空间和工位规划 | 工位/会议室/茶水间/动线 |
| **机架图** | 服务器机柜设备布局 | 机柜 U 位、设备型号、端口连接 |
| **线框图** | UI/产品原型草图 | 页面布局、交互区域、内容占位 |
| **故事板** | 视频/动画的镜头规划 | 逐格画面 + 旁白/说明 |
| **海报/日历** | 宣传物/日程表设计 | 图文混排、色彩搭配、信息层次 |

## 通用绘制流程

1. **确定比例和尺寸**：实际尺寸映射到图纸比例
2. **画边界和固定物**：墙体/机柜边框等不可移动的元素
3. **添加核心元素**：家具/设备/内容区域
4. **标注尺寸和说明**：数字 + 文字注释
5. **检查规范合规**：消防/建筑等需要符合行业标准

## 各图表要点

### 建筑平面图 / 办公室布局图
- 从外墙开始画，再画内墙，最后放家具
- 标注关键尺寸（房间长宽、通道宽度）
- 用不同颜色区分功能区域
- 动线：画出人员从入口到达各区域的最短路径

### 消防图
- 必须有：逃生路线（绿色箭头）、灭火器位置、消防栓位置、集合点
- 标注「你在这里」的当前位置
- 方向标注（指北针）
- 需要符合当地消防安全规范

### 机架图
- 标注每个设备的 U 位（占用几 U）
- 设备之间有间距标注（散热需求）
- 列出设备清单（型号/IP/序列号/端口连接）
- 前面板视图 vs 后面板视图分开

### 线框图
- 低精度：方框和占位文字即可
- 标注页面区域：导航区/内容区/操作区/页脚
- 标注交互：点击→跳转 / 滑动→展开 / 长按→菜单
- 推荐使用 draw.io 或专门的线框图工具

### 故事板
- 每格 = 一个关键画面
- 每格下方：画面描述（1 句）+ 旁白/对白（可选）
- 标注镜头运动：推/拉/摇/移
- 6-12 格足以描述 60 秒的内容

### 海报/日历
- 海报：标题最醒目 → 主视觉图 → 辅助信息 → 行动号召
- 日历：标注节假日、标记重要日期、预留备注区
- 色彩搭配：主色 ≤ 3 种 + 中性色（黑白灰）

## 自查

1. 比例是否正确？（特别是平面图和机架图）
2. 尺寸标注是否完整？
3. 是否满足行业规范要求？（消防/建筑等合规性）
