# 分析工具图

> 为什么会这样？该选哪个？——分析问题、对比选项、做出决策。

## 适用场景

- 问题根本原因分析
- 战略规划和竞争评估
- 多选项比较和决策
- 财务分析和盈利拆解

## 图表类型对比

| 类型 | 用途 | 关键特征 |
|------|------|---------|
| **SWOT 分析** | 评估内外部环境 | 四象限：优势/劣势/机会/威胁 |
| **鱼骨图** | 分析问题的根本原因 | 鱼头=问题，鱼骨=原因大类，鱼刺=具体原因 |
| **决策树** | 多选项的量化决策 | 节点=选择/事件，分支=可能结果，叶=收益/概率 |
| **杜邦分析图** | 财务盈利拆解 | 从 ROE 向下逐层分解到最底层指标 |
| **比较图** | 多选项的直观对比 | 表格/矩阵/雷达图形式均可 |
| **五力分析** | 行业竞争结构分析 | 供应商/购买者/新进入者/替代品/现有竞争 |
| **竞争分析图** | 竞品对比和市场定位 | 功能/价格/市场份额/差异化因素矩阵 |

## 通用绘制流程

1. **明确分析目的**：你要回答什么问题？
2. **选择分析框架**：根据目的选择对应的图表类型
3. **收集/填充信息**：先做信息收集，再做分析判断
4. **识别关键发现**：图表画完后，圈出最重要的 1-3 个洞察
5. **导出行动计划**：基于发现，下一步做什么？

## 各图表要点

### SWOT 分析
- 内部因素（优势/劣势）：你控制得了的
- 外部因素（机会/威胁）：你控制不了的
- 每象限 3-5 个要点，按重要性排序
- 最终目标：优势×机会 = 进攻方向；劣势×威胁 = 防御方向

### 鱼骨图（因果分析/石川图）
- 鱼头（右侧）= 待解决的问题
- 主骨 = 6 大类原因：人、机、料、法、环、测（可按场景调整）
- 每根骨上的刺 = 具体原因，追问「为什么会这样？」直到根因
- 画完后，圈出 3 个最可能的根因作为下一步验证方向

### 决策树
- 从根节点（起始决策）开始，逐层展开选择
- 每个决策节点标注：选项名称 + 条件
- 每个叶节点标注：概率 + 预期收益/损失
- 最终计算每条路径的期望值，辅助定量决策

### 杜邦分析
- 从 ROE 出发，分解为净利润率 × 资产周转率 × 权益乘数
- 每个指标继续向下分解，直到最底层可执行的财务指标
- 用箭头表示分解方向

### 比较图 / 五力分析 / 竞争分析
- 比较图：先确定比较维度，再填充数据，最后可视化
- 五力分析：每个力量用 1-5 分评估强度，标注关键证据
- 竞争分析：结合 SWOT 和五力分析的结果

## 自查

1. 分析框架选对了吗？（鱼骨图分析原因 vs SWOT 评估态势 vs 决策树做选择）
2. 信息是否充分？有无关键数据缺失？
3. 分析结果是否导向了可执行的下一步行动？
