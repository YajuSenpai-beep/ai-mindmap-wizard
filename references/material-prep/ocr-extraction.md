# OCR 提取指南 — 图片/PDF → 文本

> 把图片和 PDF 里的文字准确提取出来，是导图质量的第一道关。

## 拍照/扫描最佳实践

| 要素 | 建议 |
|------|------|
| 光线 | 自然光、均匀、避免阴影和反光 |
| 角度 | 正对拍摄，避免倾斜透视 |
| 分辨率 | 至少 1200px 宽；PDF 扫描 ≥ 200dpi |
| 背景 | 纯色背景优于彩色/渐变背景 |
| 工具 | CamScanner / Adobe Scan 优于相机直拍 |

## 图片预处理（提升识别率）

如果 AI 识别效果不佳，先预处理图片再上传：

```
处理策略（从简到繁）：
  灰度化      → 去除彩色干扰（最常用）
  对比度+50%  → 文字与背景分离
  锐化        → 增强边缘清晰度
  中值滤波    → 去除噪点（拍照噪点多时用）
  直方图均衡  → 改善过亮/过暗区域
```

**工具推荐**：
- Windows：画图（调整对比度/亮度）
- Mac：Preview（转换为灰度）
- 批量：ImageMagick 命令行，或 Python + Pillow

## PDF 三层处理策略

| PDF 类型 | 判断方法 | 提取方式 | 效果 |
|----------|---------|---------|------|
| **文字型** | 能选中文字 | 直接 Ctrl+A 复制 | 最佳 |
| **混合型** | 部分能选中、部分是图 | 文字部分复制 + 图片部分截图 | 较好 |
| **扫描型** | 完全不可选中 | 截图每一页 → 上传 AI 逐页 OCR | 取决于扫描质量 |

### 扫描型 PDF 的专项处理

1. 在 PDF 阅读器中导出页面为图片（或截图）
2. 导出分辨率 ≥ 200dpi
3. 逐页上传 AI，配合 [图片→导图重建](../ai-pipeline/image-to-mindmap.md) 中的提示词
4. 超过 10 页的 PDF，建议用 Python 工具链（pipeline.py）批量处理

## 识别后必做的质量检查

1. **乱码扫描**：快速扫一遍有没有明显乱码段
2. **数字核验**：步骤编号是否连续（1→2→3 还是 1→3→5）
3. **术语核对**：专业名词有没有变成形近字
4. **断句检查**：长段落有没有被错误截断

如果质量差 → 参考 [质量自检](../troubleshooting/quality-assurance.md) 或用 Python 工具链的 adaptive 模式重处理。
