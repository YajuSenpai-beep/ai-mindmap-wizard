# 快捷键速查 — XMind + draw.io

> 记住这些常用快捷键，效率提升 3 倍。

## XMind 核心快捷键

### 节点操作
| 操作 | 快捷键 |
|------|--------|
| 新建子主题 | `Tab` |
| 新建同级主题 | `Enter` |
| 新建父主题 | `Ctrl+Enter` |
| 编辑节点 | `Space` 或双击 |
| 删除节点 | `Delete` |

### 编辑操作
| 操作 | 快捷键 |
|------|--------|
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` |
| 复制 | `Ctrl+C` |
| 剪切 | `Ctrl+X` |
| 粘贴 | `Ctrl+V` |
| 全选 | `Ctrl+A` |
| 查找/替换 | `Ctrl+F` |

### 格式与美化
| 操作 | 快捷键 |
|------|--------|
| 加粗 | `Ctrl+B` |
| 斜体 | `Ctrl+I` |
| 下划线 | `Ctrl+U` |
| 插入联系线 | `Ctrl+L` |
| 插入外框 | `Ctrl+B`（选中多节点） |
| 插入概要 | `Ctrl+]` |
| 添加备注 | `F4` |
| 插入图片 | `Ctrl+Shift+I` |
| 插入图标 | `Ctrl+1` |

### 视图
| 操作 | 快捷键 |
|------|--------|
| 放大/缩小 | `Ctrl+滚轮` |
| 适应画布 | `Ctrl+0` |
| 聚焦模式 | `F4`（选中节点） |
| 展开/折叠 | `Ctrl+/` |
| 全屏 | `F11` |

---

## draw.io 核心快捷键

### 画布操作
| 操作 | 快捷键 |
|------|--------|
| 新建 | `Ctrl+N` |
| 保存 | `Ctrl+S` |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` |
| 删除 | `Delete` |
| 全选 | `Ctrl+A` |
| 放大/缩小 | `Ctrl+滚轮` |
| 适应窗口 | `Ctrl+H` |
| 平移画布 | 右键拖拽 或 `Space+拖拽` |

### 图形操作
| 操作 | 快捷键 |
|------|--------|
| 复制并链接 | `Ctrl+D`（复制节点并自动连线） |
| 组合 | `Ctrl+G` |
| 取消组合 | `Ctrl+Shift+G` |
| 锁定/解锁 | `Ctrl+Shift+L` |
| 置顶 | `Ctrl+Shift+]` |
| 置底 | `Ctrl+Shift+[` |
| 旋转 | `Ctrl+R`（顺时针 90°） |

### 文本
| 操作 | 快捷键 |
|------|--------|
| 编辑文本 | `Enter` 或双击 |
| 退出文本编辑 | `Esc` |
| 加粗 | `Ctrl+B` |
| 斜体 | `Ctrl+I` |
| 插入链接 | `Ctrl+K` |

### 样式
| 操作 | 快捷键 |
|------|--------|
| 复制样式 | `Ctrl+Shift+C` |
| 粘贴样式 | `Ctrl+Shift+V` |
| 清除样式 | `Ctrl+Shift+R` |

---

## 记忆优先级

### XMind：先记这 5 个
```
Tab          = 新建子主题
Enter        = 新建同级主题  
Space        = 编辑节点
Ctrl+L       = 联系线
Ctrl+]       = 概要
```

### draw.io：先记这 5 个
```
Ctrl+D       = 复制并链接（最高频！）
Ctrl+G       = 组合
Ctrl+滚轮     = 缩放
Ctrl+H       = 适应窗口
Space+拖拽   = 平移画布
```
