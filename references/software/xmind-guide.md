# XMind 操作指南

> 思维导图的首选工具。免费版功能足够日常使用。

## 核心操作流程

### 创建导图

1. 打开 XMind → **新建** → 选择模板（推荐「思维导图」或「逻辑图」）
2. 双击中心主题 → 输入标题
3. 选中中心主题 → **Tab** 创建子主题 / **Enter** 创建同级主题
4. 也可以直接导入 Markdown 文件：**文件 → 导入 → Markdown** → 选择 `.md` 文件

### 编辑节点

| 操作 | 快捷键 |
|------|--------|
| 新建子主题 | `Tab` |
| 新建同级主题 | `Enter` |
| 编辑选中节点 | `Space` 或双击 |
| 删除节点 | `Delete` |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` |

### 调整结构

- 选中节点 → 拖拽到目标位置即可调整层级
- 右侧属性面板：切换布局（思维导图/逻辑图/组织结构图/时间轴/鱼骨图）
- 选中节点 → 右键 → **结构** → 选择子分支的排列方式

### 美化

- **主题**：右侧面板 → 主题 → 一键换色
- **配色方案**：右侧面板 → 配色 → 应用到整张导图
- **图标和贴纸**：右侧面板 → 图标 → 拖到节点上标记优先级/状态
- **线条样式**：右侧面板 → 线条 → 调整粗细和颜色
- **背景**：右侧面板 → 背景 → 纯色/渐变色/自定义图片

### 导出

- **文件 → 导出** → 选择格式：
  - PNG/JPG：适合插入文档和演示
  - PDF：适合打印和分享
  - SVG：适合进一步编辑（可导入 Visio / Illustrator）
  - Markdown：导回文本格式

## 从 AI 生成导入（推荐工作流）

这是最高效的使用方式——让 AI 生成结构化内容，XMind 负责可视化：

1. 在任意 AI 工具中生成 Markdown 格式的思维导图（参考 [文本→导图流程](../ai-pipeline/text-to-mindmap.md)）
2. 复制代码 → 保存为 UTF-8 编码的 `.md` 文件
3. XMind → **文件 → 导入 → Markdown** → 选择文件
4. 导图自动生成，手动微调布局和配色

## 特殊功能

### 联系线（关联信息）
- 选中两个节点 → `Ctrl+L`（或右键 → 插入 → 联系）
- 用于标注不同分支间的逻辑关系

### 外框
- 选中多个节点 → `Ctrl+B`（或右键 → 插入 → 外框）
- 用虚线框圈出同一类内容

### 概要
- 选中多个子节点 → `Ctrl+]`（或右键 → 插入 → 概要）
- 为子分支添加总结性描述

### 备注和标签
- `F4`：为节点添加备注（不显示在主图上，点击才展开）
- 右键 → 标签 → 添加分类标签

## 常见问题

| 问题 | 解决 |
|------|------|
| 导入 Markdown 中文乱码 | 重新保存 `.md` 文件，编码选 **UTF-8** |
| 导图太大看不清 | 使用 **聚焦模式**（F4）或分段导出为多张子图 |
| 节点太多（>50） | 考虑拆分为多张导图，或用概要功能折叠 |
