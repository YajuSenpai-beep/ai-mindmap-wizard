# Word 完全指南 — 从入门到接单级

> 从 1553 个文件（217 笔记 + 218 TXT + 3 PDF + 528+ 模板）提炼。与 [WPS完全指南](wps-guide.md) 互补——WPS 指南覆盖的 Word 基础操作不在此重复。

## 邮件合并（Word 独有核心技能）

### 三种文档类型

| 类型 | 用途 | 效果 |
|------|------|------|
| **信函** | 证书、邀请函、工资条 | 每条记录独立一页 |
| **标签** | 姓名牌、物资标签 | 同一页排列多条记录 |
| **目录** | 工资条（连续无分页） | 连续输出不分页 |

### 标签类邮件合并（关键模式）

```
① 邮件→开始邮件合并→标签→选标签尺寸
② 只设计左上角第一个单元格
③ 插入合并域 + 规则→下一记录 «Next Record»（放在末尾）
④ 点击「更新标签」——自动复制到所有单元格
⑤ 预览→完成合并
```

> **陷阱**：手动复制内容到每个格 → 记录重复不前进。必须用「更新标签」。

### 薪酬数字格式化（域代码级）

工资条中 Excel 数值在 Word 中格式丢失。`Shift+F9` 切换域代码，追加格式开关：

```
小数 → { MERGEFIELD 岗位工资 \# "#,##0.00" }
百分比 → { = { MERGEFIELD 出勤率 } * 100 \# "0.00%" }
日期 → 插入→文档部件→域→Time，格式：yyyy'年'M'月'd'日'
```

> 所有反斜杠、引号、井号必须**英文半角**。

### 批量照片合并（INCLUDEPICTURE 域）

```
① Excel 照片路径列必须用双反斜杠：C:\\Photos\\emp001.jpg
② 插入→文档部件→域→INCLUDEPICTURE
③ Alt+F9 切换域代码 → 删除占位文字 → 插入合并域（照片路径列）
④ 预览时图片不显示（正常）→ 完成合并 → Ctrl+A → F9 刷新 → 图片出现
```

### 合并结果拆分为独立文件

```
① 在合并文档中为每条记录的唯一标识设「标题1」样式
② 视图→大纲 → 显示级别选「1级」
③ 显示文档→创建 → 保存 → Word 自动按标题1拆分为独立 .docx
```

### 邮件群发（Outlook+QQ邮箱）

- QQ邮箱需开启 POP3/SMTP → 生成 16 位**授权码**（非 QQ 密码）
- Outlook 手动配置：`pop.qq.com:995`(SSL) 收件 / `smtp.qq.com:465`(SSL) 发件
- 选项→高级→**取消勾选**「连接后立即发送」→ 邮件先留在发件箱供审核
- 分批策略：每次群发 ~10 封，避免 Outlook 卡死

## 表单控件与文档保护

### 开发工具选项卡（默认隐藏）

文件→选项→自定义功能区→勾选「开发工具」

| 控件 | 用途 | 关键设置 |
|------|------|---------|
| 下拉列表 | 预定义选项（性别/部门） | 属性中添加显示名和值 |
| 日期选取器 | 日历选日期 | 设格式如「XXXX年XX月XX日」 |
| 复选框 | 是/否 | 修改 Caption 文字 |
| 选项按钮 | 单选 | **同组所有按钮 GroupName 必须相同** |
| 纯文本 | 自由输入 | 设占位符文字 |

**设计模式**：配置控件时开启，完成后关闭（按钮不再高亮），控件才能交互。

### 三种保护模式

| 模式 | 效果 | 操作 |
|------|------|------|
| **密码加密** | 需密码打开/修改 | 文件→信息→保护文档→用密码加密 |
| **限制编辑+例外区域** | 只有指定区域可编辑 | Ctrl 选中例外区 → 审阅→限制编辑→「不允许任何更改」→例外→每个人 |
| **仅允许填写窗体** | 用户只能 Tab 切换控件，静态文字锁定 | 限制编辑→仅允许「填写窗体」→启动强制保护 |

**空密码防误触**：锁定修订时设空密码 → 不加密，只增加确认步骤防误关。

## 宏与 VBA

### 录制宏

```
开发工具→录制宏 → 命名（无空格）→ 存到「Normal.dotm」（全局）或当前文档
→ 键盘→物理按下快捷键组合（如 Alt+Ctrl+0）→ 分配→关闭→录制开始
→ 执行要录制的操作→停止录制
```

### 宏安全性

**警告**：永远不要选「启用所有宏」——常见病毒入口。日常用「禁用所有宏并发出通知」。

### 样式管理器（Organizer）

开发工具→文档模板→管理器：可在文档和模板间复制**样式/宏/自动图文集/工具栏**。

## Word 独有功能

### Word → PPT 自动转换

隐藏在「不在功能区中的命令」里：
```
① 自定义功能区→「不在功能区中的命令」→添加「发送到 Microsoft PowerPoint」
② Word 中：标题1→PPT 标题页 / 标题2→PPT 幻灯片标题 / 标题3→PPT 项目文字
③ 设置好大纲级别→导航窗格验证→单击命令→PPT 自动生成
```
> 图片和表格不会转移，需手动复制。

### 自动更正作为输入快捷方式

文件→校对→自动更正选项：
- **纯文本**：设短代码（如 `addr1`）→自动扩展为长文本（公司地址）
- **带格式**：先选中格式化内容（含图片/表格）→打开自动更正→内容以「带格式文本」出现→设触发词（如 `#logo`）
- 陷阱：触发词不能是常用词（设 `logo` 会导致每次输入 `logo` 都被替换）

### 文本框链接（主持手卡制作）

```
① 创建文本框→Ctrl+Shift+拖动复制多个
② 预处理文字：行距设为「固定值」（如16磅）→防止微软雅黑间距过大
③ 粘贴全文到第一个文本框→绘图工具→创建链接（光标变茶杯图标）→点击下一个文本框
④ 溢出文字自动流到链接的文本框
```

### 电子图章/签名

- 外部工具生成印章 PNG（透明背景）
- Word 中插入→设为「浮于文字上方」→自由定位
- 手写签名：拍照→去背景→插入为透明 PNG
- **法律提醒**：此方法仅限内部/非法律用途。法律效力电子签名需 CA 认证。

### 段前分页（优于手动分页符）

段落对话框→换行和分页→勾选「段前分页」。比手动 `Ctrl+Enter` 更干净，内容改动后不会产生幽灵空白页。

### 文档网格行距问题

换微软雅黑 5pt 时行距爆炸 → 原因：雅黑实际字高（18.56pt）超出文档网格行距（15.6pt），被向上取整。
- 方案 A（全局）：布局→页面设置→文档网格→「无网格」
- 方案 B（局部）：段落→缩进和间距→取消勾选「对齐到网格」

### 删不掉的最后一页

显示/隐藏标记诊断 → 拖动垂直标尺顶部页边距标记微调 → 或调最后一个表格的段落行距（从 1.21 逐步降到 1.13）。

## 接单全流程经验（来自 PDF）

### 服务分层

| 层级 | 服务 | 单价 |
|------|------|------|
| 基础 | 文字录入、格式调整、PDF/Word 互转、自动目录 | 1-2 元/页（纯文字） |
| 进阶 | 论文排版、简历优化、公式编号、文档美化 | 20-50 元/千字 |
| 定制 | 书籍排版、批量文档处理、多人协作整理 | 面议 |

**附加费**：加急 +20~50 元 / 封面设计 10-20 元 / 复杂公式表格 +10~30 元。

### 获客渠道

| 渠道 | 特点 |
|------|------|
| 猪八戒/一品威客 | 企业订单、平台担保，但抽成 10-20% |
| 闲鱼/淘宝 | 个人客户、自主定价、无抽成 |
| QQ群/小红书/抖音 | 新手快速接小单，注意防诈骗 |
| 私域转介绍 | 无抽成、沟通成本低，长期核心来源 |

### 沟通铁律

**所有需求文字留痕，避免语音沟通。**
三问：文档用途？格式规范？交付时间+是否加急？

### 风控

- 定金 30-50% → 初稿截图确认 → 尾款到账发源文件
- 免费修改 1-2 次，重大变更另收费
- 交付后 24-72h 删除客户文件
- 文档隐性水印：`=CELL("filename")`
