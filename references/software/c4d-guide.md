## 核心操作

### 视图控制
`Alt`+左键=旋转 | `Alt`+中键=平移 | `Alt`+右键=缩放 | 中键点击=四视图 | `H`=最大化全部 | `O`=最大化选中

### 对象操作
`W`/`R`/`T`=移动/旋转/缩放 | `C`=塌陷为可编辑对象 | `Alt+G`=打组 | `Ctrl`+拖动=复制 | `Shift`+新建=子级 | `Alt`+新建=父级

### 界面五区心智模型
**创建**(生成器/样条) → **存储**(对象管理器) → **移动**(工具栏) → **调整**(属性管理器) → **查看**(模式工具栏)

## 建模技法

### 多边形建模核心工具

| 工具 | 用途 | 关键注意 |
|------|------|---------|
| 挤压 Extrude | 选面→右键挤压 | 勾选「创建封顶」=实体，不勾=空心 |
| 内部挤压 Inset | 选面向内缩 | 配合挤压做出台阶/沉台效果 |
| 倒角 Bevel | 边/面倒角 | 偏移量+细分数 |
| 循环切割 Loop Cut | 加循环边 | **卡线必备**——细分曲面前加边缘保持硬边 |
| 溶解 Dissolve | 消除多余边 | 自动缝合面（Delete会留洞） |
| 桥接 Bridge | 连接两边 | 必须在同一对象内（先用连接+删除合并） |
| 封闭多边形孔洞 | 点击开口边缘 | 自动生成封闭面 |
| 适配圆 Fit Circle | 选四边面→变圆 | 配合挤压做出圆形结构 |
| 多边形画笔 | 万能工具 | `Ctrl`+拖=挤出体积；投射结果=吸附到表面 |

### 生成器建模

| 生成器 | 做法 | 用途 |
|--------|------|------|
| **细分曲面** | 丢入子级 | 平滑几何体（需配合循环切割卡线） |
| **旋转 Lathe** | 前视图画半轮廓样条→应用 | 旋转对称体（瓶/杯） |
| **扫描 Sweep** | 截面+路径样条 | 管状几何体 |
| **挤压 Extrude** | 2D样条+挤压 | 厚度（Z轴移动） |
| **放样 Loft** | 多个截面样条 | 过渡/有机形态 |
| **布尔 Boolean** | 多模型为子级 | 合并/相减/相交→重构网格→倒角 |
| **体积生成+体积网格** | 融合几何体 | 有机融合（控制体素精度） |
| **晶格 Lattice** | 丢入子级 | 顶点→球+边→柱框架 |

### 变形器

**弯曲**（需足够分段）| **扭曲** | **FFD**（匹配到父级+增加网格点）| **样条约束**（模型沿样条变形，需足够分段）| **置换**（灰度图驱动表面起伏）| **碰撞**（变形前启用物理碰撞）

### 拓扑铁律

**四边形理想** → 细分和变形结果可预测。**三角形不可避免** → 非变形区可用。**N-gon（5边+）避免** → 细分时产生不可预测伪影。预防：球体类型选「六面体」、挤压封顶选「网格」。

## 材质（OC渲染器）

### 材质类型速选

| 类型 | 用途 |
|------|------|
| **漫射 Diffuse** | 哑光（石头/布料/纸板），无反射高光 |
| **光泽 Glossy** | **主力**——有反射的表面（塑料/油漆/金属）。调粗糙度+IOR |
| **镜面 Specular** | 透明/折射（玻璃/水/液体）。开「伪阴影」+「影响Alpha」|
| **发光 Emission** | 自发光（灯/LED屏） |
| **通用 Universal** | 多层复合（肥皂泡等复杂材质） |

### 关键参数
- **IOR**：塑料~1.5，金属>8（或用IOR=1+反射法）
- **粗糙度**：0=镜面抛光，0.3-0.5=哑光/缎面
- **菲涅尔节点**：边缘vs中心反射差异 → 连到Mix的「数量」做边缘增强
- **薄膜层**：彩虹色干涉效果（肥皂泡/油膜）

### 纹理工作流
- **凹凸 Bump**：灰度高度图，**仅视觉**，轮廓不变
- **法线 Normal**：RGB方向信息，比Bump精确。**两者不可同时用**
- **置换 Displacement**：物理移动顶点，轮廓真实改变，需网格细分
- **不透明度**：黑=透明，白=不透明。反转用渐变节点

### PBR贴图映射
**镜面流**：漫射(纯色) + 镜面(含反射颜色+强度) + 粗糙度
**金属流**：基础色(所有颜色) + 金属度(灰度) + 粗糙度
**关键**：按贴图**视觉内容**映射到正确通道，不靠文件名。灰度贴图(粗糙度/金属度)用**浮点**节点类型省显存。

### 材质技法
- **磨砂玻璃**：镜面材质+加粗糙度
- **金属**：关漫射，镜面设白/浅灰，调粗糙度
- **拉丝金属**：噪波(方向型)→凹凸通道，缩放控纹理粗细，旋转45°
- **标签/贴花**：彩色图→漫射，黑白版→不透明度，边界模式「修剪」
- **圆角节点**（OC）：连到法线通道，「精确」模式——在硬边模型上**渲染时伪造倒角**

## 灯光（产品照明叠层法）

### 灯型选择
**日光**（平行光/长阴影/调太阳尺寸=阴影软硬）| **区域光**（最万能/调形状大小/软阴影）| **聚光灯**（锥形/硬阴影/戏剧强调）| **HDR环境**（图片全局照明/旋转改变方向/与可见环境分离）

### 产品照明叠层（从零开始）

```
① 黑色环境（环境色设黑，从零起跑）
② 主光 Key（侧面区域光，最大强度→决定阴影方向和体积）
③ 补光 Fill（对面方向，较低强度→揭示阴影细节但不压平）
④ 轮廓光 Rim（后侧小区域光→分离产品与背景）
⑤ 细节光（微型区域光照特定特征→必须用排除）
⑥ 渐变光（区域光+渐变纹理→平滑亮暗过渡）
⑦ 产品/场景分离（产品灯排除场景，场景灯排除产品）
⑧ 背景光（自发光平面或独立灯组做背景渐变）
```

### 光影质量
- 灯越大=阴影越软 | 不要从相机角度打光（必然扁平）| 所有灯关「摄像机可见」和「阴影可见」
- 反光板/挡板：用平面+暗色/反射材质遮挡或反射光线

## 渲染输出

- **预览**：最大采样300-500 | **最终**：2000+
- **模式**：路径追踪（物理准确）| 漫射/光泽深度8-16 | GI钳制1-10
- **摄像机成像**：启ACES或d65sRGB | 调高光压缩/伽马/暗角
- **多通道/AOV**：OC设置→渲染AOV组→输出漫射/反射/透射/降噪通道
- **格式**：OpenEXR 16位 | **材质ID通道**=后期按材质选择的关键

## 动画与动力学

### 关键帧
- `F`=自动关键帧 | 时间线移→改参数→点空心圆 | `Shift+F3`=动画窗口 | 曲线编辑器调缓入缓出

### 刚体/柔体/布料
- **刚体**：不变形物体，调质量/弹性/摩擦 | 项目设置→模拟→重力(-981)
- **柔体**：刚体标签→属性里开「柔体」| 弹簧=弹性，压力=膨胀(0=瘪/50=紧绷/100+=炸)
- **布料**：高分段平面+布料标签 | 调「弯曲」=柔软度 | 「撕裂」做撕破效果
- **碰撞体**：被动碰撞对象，单独加标签

### 样条动力学（绳索/线缆）
头发标签→样条动力学 | 头发约束(固定点到物体)+弹簧连接器(定义物理关系)+力场(风)

### 骨骼绑定
**关节**(骨骼链)→**蒙皮**(变形器，映射骨骼到顶点)→**权重**(每顶点0-100%影响)→**IK**(反向动力学：移目标=系统计算父级旋转)/**FK**(正向：逐个旋转)

## AI + C4D

### DeepSeek 脚本开发
```
工具链：VSCode + C4D Bridge扩展 + AI(Cline) + DeepSeek API
流程：自然语言→AI生成Python→Bridge传输→C4D执行→控制台反馈→迭代
策略：拆复杂任务为小步→每步测试→备份可用版本
调试：打印对象属性(GetTypeName/GetName)获取正确API标识
递归遍历：GetDown(子级)/GetNext(同级)在层级中查找嵌套对象
```

### 实战脚本
- **一键清空材质球**：删所有材质→装到脚本管理器→拖到工具栏
- **智能删材质**：删选中材质+自动清理残留「?」标签→设快捷键
- **批量轴复位**：递归重置整层级轴心；本地版(绝对精度/转实例)vs Pro版(保留实例/性能)

### AI建模管线
```
① 上传参考图到AI服务(混元3D)→下载FBX基础模型
② 优化：备份→重构网格减面→从高模备份投影回细节
③ UV展开→导入Substance Painter→智能材质→校准参考图→导出PBR贴图
④ OC自动识别贴图后缀(_BaseColor/_Roughness等)→灰度图改浮点节点类型
```

## 常见陷阱

| 陷阱 | 对策 |
|------|------|
| 变形器效果差 | 模型分段不够→增加分段 |
| 直接用Delete删边 | 用溶解(Dissolve)，否则留洞 |
| 细分曲面后全变成一团 | 没做循环切割卡线 |
| 中英文输入法冲突 | 快捷键失效→切英文输入法 |
| 灯渲染为可见白色方块 | 关「摄像机可见」|
| 产品照明扁平 | 不要从相机角度打光 |
| 直接删材质球留「?」标签 | 用智能删材质脚本 |
| 动画速度不对 | 项目FPS≠输出FPS |
| Bump和Normal同时连 | 冲突，Normal已含Bump信息 |
| 灰度贴图用纹理节点 | 用浮点节点→省VRAM |
