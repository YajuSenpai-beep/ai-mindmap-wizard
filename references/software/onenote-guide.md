# OneNote 完全指南 — 从入门到领导级

> 从 2 份 PDF + 30 份视频笔记提炼。OneNote 不是记事本，是信息整合引擎。

## 定位

OneNote = 自由画布式数字笔记本。核心能力四环：**捕获 → 云同步 → 编辑整理 → 共享传播**。

## 版本选择

| 版本 | 优势 | 劣势 | 适合 |
|------|------|------|------|
| **OneNote 2016** | 功能最全、支持本地存储、插件丰富 | 界面传统 | 主力用户、需本地存储 |
| **OneNote UWP** | 界面现代、触控优化、同步引擎更好 | 功能精简、仅云端 | 触控设备、轻量使用 |

> 两者可共存，建议主力用 2016。

## 核心结构（五层金字塔）

```
笔记本 (Notebook)           ← 最顶层：按人生领域/项目分类
  └─ 分区组 (Section Group)  ← 可选层：归类相关分区
       └─ 分区 (Section)     ← 次级：主题标签页
            └─ 页 (Page)     ← 内容承载层
                 └─ 子页     ← 最多两级子页
```

| 全局搜索 | `Ctrl+E` |

|------|--------|

| 操作 | 快捷键 |

### 标记（核心效率工具）

| 标记类型 | 快捷键 |
|---------|--------|
| 待办事项 | `Ctrl+1` |

完整快捷键参考 [快捷键速查](keyboard-shortcuts.md)。

## 信息捕捉（PDF 全功能详解模块一/二）

### 多形态文本与画布
- 自由画布布局：文本框、图片、附件自由拖拽，任意位置摆放
- 多级标题（标题1-6）、段落缩进、换行（`Shift+Enter`，不新建段落）
- 手写与绘图：Windows 版支持压感手写、墨迹批注、墨迹转形状、墨迹转文本
- 跨平台粘贴：可选择「带格式粘贴」/「仅粘贴文本」/「图片」

### 多媒体与附件
- 插入图片：本地/网络图片、屏幕截图（`Win+Shift+S` 截图后直接粘贴）
- 录音：内置录音工具，边录边记，播放时自动跳转到记录位置
- 视频：插入在线视频（支持 YouTube）或本地视频文件
- 附件：插入任意格式文件（Word/Excel/PDF/压缩包），选择「附加文件」或「插入链接」

### 表格操作

| 操作 | Windows 快捷键 |
|------|---------------|
| 插入表格 | `Ctrl+Shift+T` |
| 当前行上方插入行 | `Ctrl+Shift+Enter` |
| 当前行下方插入行 | 光标在行尾按 `Enter` |
| 当前列左/右侧插入列 | `Ctrl+Alt+←/→` |
| 删除当前行/列 | `Ctrl+Shift+-` / `Ctrl+Alt+-` |
| 移动到下/上个单元格 | `Tab` / `Shift+Tab` |
| 选中整个表格 | `Ctrl+A` 两次 |

> 快捷创建表格：输入文字后按 `Tab` 自动转为表格，继续 `Tab` 增加行。

### 搜索（多维度）

| 操作 | 快捷键 |
|------|--------|
| 当前页面搜索 | `Ctrl+F` |
| 所有笔记本全局搜索 | `Ctrl+E` |
| 替换文本 | `Ctrl+H` |
| 按日期/作者/标记筛选 | 搜索框内选择筛选条件 |

## 个性化与模板（PDF 全功能详解模块四）

- **页面设置**：自定义背景颜色、纸张样式（横线/网格/点阵）
- **笔记本封面**：设置颜色标识，快速区分不同笔记本
- **内置模板**：会议记录、课堂笔记、项目计划等开箱即用
- **自定义模板**：设计好页面布局 → 插入 → 页面模板 → 将当前页另存为模板
- **页面基准线**：视图 → 页面设置 → 基准线 → 选择网格/横线辅助对齐

## Office 生态集成（PDF 全功能详解模块六/七）

- **Outlook 联动**：从邮件/日历事件一键创建关联笔记；标记的待办事项可同步到 Outlook 任务
- **Word/Excel/PPT**：直接插入文档内容或嵌入文件；PPT 可「打印到 OneNote」逐页批注
- **Teams 集成**：在 Teams 内直接访问和编辑笔记
- **链接笔记**：审阅 → 链接笔记 → 从其他 Office 文档粘贴内容时自动关联源文件
- **Zapier/API**：对接 Slack、Figma 等第三方工具

## 高级与特色功能（PDF 全功能详解模块七）

- **窗口停靠**：`Ctrl+Alt+D` 将 OneNote 固定在屏幕边缘
- **多窗口**：`Ctrl+M` 打开新窗口，同时查看不同笔记本
- **同义词库**：选中单词 → `Shift+F7` 打开同义词库
- **拼写检查**：`F7`，拼写错误自动红色波浪线标记
- **快捷键自定义**：文件 → 选项 → 自定义功能区 → 键盘快捷方式
- **即时计算**：输入算式后加 `=` 按空格，自动计算结果（浮点数，非精确计算）
- **内部链接**：右键段落 → 复制指向段落的链接 → 粘贴到目录页 → 点击跳转
- **长图片导出**：选中内容 → 粘贴为图片 → 另存为 PNG/JPG

## 高阶功能

### 数学公式（理工科核心）

- 调出公式编辑器：`Alt+=`
- 线性输入法：`\代码 + 空格`（类似 LaTeX）
- 示例：`\alpha` → α | `\sqrt` → √ | `\int` → ∫ | `\sum` → Σ | `\frac` → 分数 | `\matrix` → 矩阵
- 必须在**英文输入法**下输入代码

### OCR 文字识别

- 插入图片 → 右键 → 「复制图片中的文本」
- 中文 OCR 效果有限，建议截图后上传 AI 工具替代
- 提升识别率：图片预处理（灰度化+对比度增强）

### 录音笔记

- 插入 → 录音 → 边录音边打字
- 播放时自动跳转到记录时的笔记位置
- 快捷键：`Ctrl+Alt+P` 播放 / `Ctrl+Alt+S` 停止

### 插入 PPT/PDF

- **PPT**：拖入文件 或 从 PPT 打印到 OneNote
- **PDF**：插入 → 文件打印样式 → **取消勾选**「将长打印输出插入到多个页面」
- 可在插入后的图片上直接批注

### 插件生态

| 插件 | 用途 | 费用 |
|------|------|------|
| **OneNote Clipper** | 浏览器一键剪辑网页内容 | 免费 |
| **OneTastic** | 宏管理器，自动目录/编号/日历 | 免费 |
| **OneNote Gem** | 数百项高级功能（查找替换/自定义样式/自动编号） | 付费 |

### 分区加密

- 右键分区 → 密码保护 → 加密
- 5 分钟无操作自动锁定
- 加密粒度为**整个分区**，无法单页加密

## 高效工作流（四步知识内化法）

```
① 导入    → 将外部材料插入 OneNote（PDF/网页/图片/音频）
② 标记    → 用标记系统标注关键信息（待办/重要/疑问）
③ 思考扩展 → 对标记内容添加注释、提问、关联其他笔记
④ 结构化   → 整理为「笔记本→分区→页」层级体系
```

> 核心原则：**主动加工 > 被动记录**。不要只是往 OneNote 里塞东西。

## 分场景应用

### 高效读书
1. 导入：用 Clipper 剪辑书评/摘要，或拍照插入重点页
2. 标记：标注核心观点（重要标记）+ 疑问（疑问标记）
3. 思考：每章写一段自己的理解，关联已有知识
4. 结构化：按「书→章→节」建立笔记本层级

### 学生听课
1. 录音 + 手写/打字双线记录
2. 用多级列表构建知识框架（一级=大标题，二级=要点，三级=细节）
3. 课后走「事后整理」：逻辑重组 + 信息精简 + 标注疑问
4. 用子母图技巧（参考 [子母图](../methodology/mother-child-diagram.md)）管理多学科知识

### 职场会议
1. 从 Outlook 日历直接创建会议笔记（自动关联参会人+议程）
2. 录音 + 标记行动项（待办标记）
3. 会议结束后生成标记摘要页 → 一键导出待办清单
4. 共享笔记本给团队，实时协作编辑

## 管理最佳实践

### 备份策略
- **云同步**：登录 Microsoft 账户自动同步到 OneDrive
- **本地备份**：定期将笔记本文件夹复制到外部硬盘
- **PDF 导出**：`Ctrl+P` → 虚拟打印机（不建议用「导出为 PDF」，图片会模糊）

### 跨设备一致性
- **统一默认字体**（如微软雅黑），否则不同设备间文字会错位
- PDF 插入使用「打印」方式而非拖入（打印方式将每页转为图片，跨设备一致）

### 共享与协作
- 云端笔记本可共享，支持编辑/只读权限
- 多人同时编辑可见编辑者头像和位置
- 版本历史可回溯任意时间点快照
- **共享链接仅在笔记本位置不变时有效**

## 常见误区

| 误区 | 事实 |
|------|------|
| 「OneNote 就是个电子笔记本」 | 定位是信息整合处理工具，四环闭环 |
| 「UWP 是简化版，不能用」 | 触控和同步更好，与 2016 互补 |
| 「多塞内容就是做笔记」 | 核心是主动加工，不是被动囤积 |
| 「OCR 能完美识别中文」 | 中文 OCR 效果有限，建议用 AI 工具替代 |
| 「导出 PDF 就行了」 | 「导出为 PDF」图片会模糊，应通过「打印」生成 |
| 「子页可以无限嵌套」 | 最多两级子页 |
| 「加密后立即锁定」 | 默认 5 分钟无操作后才自动锁定 |
