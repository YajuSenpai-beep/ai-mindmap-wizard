## 核心结构：三大组件 + 通用概念

### 文字（Word 等价）

**文档结构层级**：
```
节 (Section)  ← 独立页面格式单元
  └─ 段落 (Paragraph)  ← 格式设置基本单位（两个段落标记之间的内容）
       └─ 字符 (Character)
```

**核心概念速查**：

| 概念 | 说明 | 快捷键 |
|------|------|--------|
| 硬回车 | 创建新段落（段落标记¶） | `Enter` |
| 软回车 | 段内换行不分段（↓） | `Shift+Enter` |
| 分页符 | 强制换页 | `Ctrl+Enter` |
| 分节符 | 创建独立格式区域 | 页面布局 → 分隔符 |
| 样式 | 预设格式集合（¶=段落样式，A=字符样式） | `Ctrl+Alt+1~9` 标题 |
| 大纲级别 | 目录生成依据（标题1~9已预设） | 引用 → 添加文字 |
| 制表位 | 不使用表格的精确列对齐 | 标尺点击设定位点，`Tab` 跳转 |
| 域 | 动态内容（目录/题注/页码） | `F9` 更新，`Alt+F9` 切换代码 |

**样式-编号-大纲三位一体**：`编号级别 ↔ 对应样式 ↔ 大纲级别`，一次设置，全局联动。

### 表格（Excel 等价）

| 概念 | 说明 |
|------|------|
| 工作簿 | 表格文档文件，可含多个工作表 |
| 公式 | 以 `=` 开头 |
| 填充柄 | 单元格右下角十字，拖拽/双击复制或序列填充 |
| 超级表（`Ctrl+T`） | 动态扩展+自动计算+切片器 |
| 数据透视表 | 多维度分类汇总的核心工具 |
| 选择性粘贴 | 粘贴为值/转置/批量运算/跳过空单元格 |

### 演示（PPT 等价）

- 大纲视图编辑同步到幻灯片（反之不生效）
- 母版统一全篇样式
- 内置模板 + 稻壳模板库

## WPS 文字核心操作

### 格式设置

| 操作 | 快捷键 |
|------|--------|
| 字体对话框 | `Ctrl+D` |
| 加粗/倾斜/下划线 | `Ctrl+B/I/U` |
| 上标/下标 | `Ctrl+Shift+=` / `Ctrl+=` |
| 增大/减小字号 | `Ctrl+]` / `Ctrl+[` |
| 左/中/右/两端对齐 | `Ctrl+L/E/R/J` |
| 格式刷（单击一次/双击连续） | 功能区按钮 |

### 段落设置

| 操作 | 快捷键 |
|------|--------|
| 增加/减少缩进 | `Tab` / `Shift+Tab` |
| 项目符号 | `Ctrl+.` |
| 编号列表 | `Ctrl+/` |
| 换行和分页选项 | `Ctrl+D` → 段落 → 换行和分页 |

**段落换行和分页关键选项**：
- 孤行控制：防止段落最后一行单独出现在下一页
- 与下段同页：标题与正文保持同页
- 段中不分页：整个段落不被分页符打断
- 按中文习惯控制首尾字符：标点不出现在行首（必勾）

### 查找替换（通配符核心）

| 通配符 | 含义 | 示例 |
|--------|------|------|
| `?` | 任意单字符 | `?国` 匹配 "中国""美国" |
| `*` | 任意多字符 | `第*部分` |
| `[x-y]` | 字符范围 | `[0-9]` 数字，`[一-龥]` 汉字 |
| `[!x-y]` | 排除范围 | `[!0-9]` 非数字 |
| `{n}` | 前字符恰好 n 次 | `[0-9]{3}` 三位数 |
| `{n,}` | 前字符至少 n 次 | |
| `@` | 前字符一次及以上 | |
| `( )` | 分组 | 替换中用 `\1` `\2` 引用 |
| `^p` | 段落标记 | |
| `^t` | 制表符 | |

**实战案例**：提取邮箱 `[A-Za-z0-9]{1,}\@[A-Za-z0-9\.]{1,}`，提取中文段落 `[一-龥]*^p`，统一编号 `([0-9]{1,})[.．、]` → `\1、`。

### WPS 独有：文字工具（11 个集成按钮）

位于「开始」选项卡，一键格式整理：
- **智能格式整理**：删除空段 + 首行缩进 2 字符（从网页复制后最常用）
- **段落重排**：合并多段为一段
- **转为空段分割风格**：取消缩进 + 段间加空行
- 删除空段/删除段首空格/删除空格/删除换行符/换行符转回车/首行缩进/首行缩进转空格/增加空段

### 分节与页眉页脚

```
分节符 ≠ 分页符
  分页符：只换页，不创建独立格式区域
  分节符：创建可独立设置页面格式的"节"
    - 下一页：分节 + 分页
    - 连续：分节不分页（同页内不同格式）

页眉页脚：
  - 默认修改一处，整节所有页生效
  - 首页不同 / 奇偶页不同
  - 同前节（链接到前一条页眉）：分节后默认链接，断开后独立
```

### 长文档排版工作流

```
① 设置页面（纸张/页边距/文档网格）
② 定义样式（标题1~9 + 正文 + 多级编号联动）
③ 录入内容，应用样式
④ 插入题注（图表自动编号）+ 交叉引用
⑤ 分节符划分章节，设置各节页眉页脚
⑥ 生成目录（引用 → 目录 → 自动目录）
⑦ 最后更新：全选 → F9 刷新所有域 → Ctrl+P 打印预览
```

## 实战技巧与陷阱（来自 105 份音频转录）

### 表格核心陷阱
- **绿色三角警告**：单元格左上角绿色三角 = 存储为文本。能做简单加减，但 `SUM` 忽略它。SUM 返回 0？先查绿色三角。
- **单元格格式只改显示，不改值**——公式栏才是真实值。
- **千万不要在数字后打单位**（如「50元」）：值变文本，计算报废。用自定义格式 `0"元"`。
- **选择性粘贴能做算术**：复制一个数 → 选中区域 → 选择性粘贴 → 加/减/乘/除。
- **SUBTOTAL 1-11 vs 101-111**：筛选时无区别。**手动隐藏行**时 109 系列不算隐藏数据，9 系列照算。
- **OFFSET 不自动显示数组**：WPS 不自动溢出。要看到完整结果 → 公式栏选中公式 → F9。

### 查找替换核心陷阱
- **替换时格式设错位置**：格式设在了「查找内容」而非「替换为」——最常见的失败原因。
- **光标位置影响范围**：务必 `Ctrl+Home` 回文档开头再执行全部替换。
- **删除英文空格用文字工具，别用替换**：替换会把单词间空格全删。文字工具 → 删除空格智能保留单词间的一个半角空格。
- **通配符下查找英文 `?` 必须转义** `\?`——否则匹配所有单字符，灾难性。

### 制表位核心陷阱
- **设置/清除/修改前必须先全选目标段落**。只选一段时拖标尺只影响该段。
- **往下拖 = 删除制表位**，手一偏就误删。
- **第一下 Tab 没反应？** 文字太多堵住了。继续操作即可，每个位置只按一下 Tab。

### 分节与页码核心陷阱
- **分页符 ≠ 分节符**。分页只换页不创建独立格式区。只有分节符才能独立设置页面格式。
- **删除分隔符唯一方法**：光标定位到符号**前面** → Delete。Backspace 无效。
- **「同前节」默认高亮**：要让该节页眉页脚独立，必须先点击此按钮断开链接。

### 编号与样式核心陷阱
- **标题样式默认勾选「与下段同页」「段中不分页」**——文档中莫名其妙大片空白的元凶。手动取消。
- **修改样式里编号时不要右击最后一级的样式**——易错乱。右击标题一或标题二来改。
- **「后续段落样式」设正文**：应用标题样式后回车 → 自动变正文，保持纯净。
- **新建样式勾了「同时保存到模板」** = 永久写入 WPS 系统，删不掉。

### 打印与导出核心陷阱
- **页面背景（含图片背景）不打印**。需打印背景 → 通过页眉页脚插入图片。
- **稿纸可打印，网格线不打印**。
- **非会员输出图片有水印**。

### 审阅核心陷阱
- **「接受所有显示的修订」vs「接受所有修订」**：前者只处理当前筛选出的，后者处理全部。两按钮紧挨，名字只差两字。
- **比较文档 = 灾难恢复**：同事关了修订直接改 → 审阅 → 比较 → 指定原文档和修订文档 → 自动差异报告。

### 其他高效技巧
- **`Alt+Enter`** = 单元格内换行；**`F4`** = 重复上一步；**双击格式刷** = 连续刷；**`Ctrl+Shift+1`** = 一秒去小数
- **三个减号+回车** = 细横线；三个等号 = 双横线；三个井号 = 隔行线
- **批量导出文档所有图片**：文件 → 另存为 → 网页(.html) → 生成同名文件夹含原图
- **一次性合并几十个文件的文字**：插入 → 对象 → 文件中的文字
- **桌面右键新建的文档已保存**；软件内 Ctrl+N 新建的**未保存**——关掉就没了
- **删 WPS 首页打开记录时不要勾「同时删除文件」**——源文件会被物理删除

### 函数速查

**数学与统计**：

| 函数 | 语法 | 用途 |
|------|------|------|
| SUM | `=SUM(range)` | 求和 |
| SUMIF | `=SUMIF(条件区,条件,[求和区])` | 单条件求和 |
| SUMIFS | `=SUMIFS(求和区,条件区1,条件1,...)` | 多条件求和（注意求和区第一位） |
| SUMPRODUCT | `=SUMPRODUCT((条件1)*(条件2))` | 多条件计数/求和 |
| SUBTOTAL | `=SUBTOTAL(109,range)` | 仅对可见单元格（109=忽略隐藏的求和） |
| RANK | `=RANK(值,区域)` | 排名 |
| RANDBETWEEN | `=RANDBETWEEN(底,顶)` | 随机整数 |

**查找与引用**：

| 函数 | 语法 | 用途 |
|------|------|------|
| VLOOKUP | `=VLOOKUP(查什么,在哪查,返回第几列,0)` | 垂直查找 |
| XLOOKUP | `=XLOOKUP(查什么,查找列,返回列,"未找到",0)` | 升级版（反向/通配符/内置容错） |
| INDEX+MATCH | `=INDEX(返回列,MATCH(查什么,查找列,0))` | 比 VLOOKUP 更灵活 |
| INDIRECT | `=INDIRECT(文本)` | 文本→引用（二级下拉菜单核心） |

**逻辑**：`IF` / `IFS`（替代嵌套IF）/ `IFERROR`（屏蔽错误）

**日期**：`DATE` / `MONTH` / `YEAR` / `TODAY` / `WEEKDAY` / `EOMONTH` / `NETWORKDAYS`

**文本**：`MID` / `TEXT` / `SUBSTITUTE`

### 数据透视表关键陷阱（来自转录）

- **自动范围不可信**：WPS 自动检测的数据范围不总是正确。插入透视表前**必须验证**选中区域。
- **先转超级表（`Ctrl+T`），再建透视表**：新增行后只需刷新透视表即可自动纳入，无需每次手动扩展数据源。
- **数值格式 vs 设置单元格格式**：透视表内右键用「数值格式」只改显示；「设置单元格格式」改底层，两者不同。
- **双击汇总值 = 自动钻取明细**：双击任意汇总单元格，WPS 生成新工作表列出构成该值的所有明细行。
- **复制透视表代替新建**：需要不同视角时，复制粘贴已有透视表 → 交换行列字段即可，不用从零创建。

### 日期与格式技巧

- **自定义格式 `D`**：只显示日期数字（1~31），隐藏年月。
- **`AAA` = 短星期**（「五」），**`AAAA` = 长星期**（「星期五」）——中文版 WPS 专属。
- **`=DATE($B$1,$D$1,1)` 生成首日**：后续用 `=前一格+1` 填充，不必重复调 DATE。
- **拼接公式中的中文必须用英文双引号**：`=B1&"年"&D1&"月考勤表"`——中文引号报错。
- **微调项（Spinner Button）**：插入 → 窗体 → 微调项 → 设置最小值/最大值/步长 → 最关键一步：**单元格链接**（否则按钮无效）。

### 条件格式实战

- **周末高亮**：`=WEEKDAY(date,2)>5`（参数 2 = 周一为 1，周六 6，周日 7）
- **法定假日高亮**：`=COUNTIF(节假日列, date)=1`（手动维护全年节假日列表）
- **隔行条纹**：`=ISODD(ROW())`，支持 Ctrl 多选非连续区域批量应用
- **隐藏非本月日期**：`=MONTH(date)<>目标月份`，自定义格式设为 `;;;`

### 实战案例

**身份证信息提取**：
```
籍贯：=VLOOKUP(MID($A2,1,6),地区代码表!$A:$B,2,FALSE)
性别：=IF(MOD(MID($A2,17,1),2)=1,"男","女")
年龄：=YEAR(TODAY())-MID($A2,7,4)
生日：=IFERROR(TEXT(MID($A2,11,4),"0月00日"),"")
```

**动态考勤表**：
```
标题：=B1&"年"&D1&"月考勤表"
首日：=DATE($B$1,$D$1,1)，后续 =前一格+1
隐藏非本月：条件格式 =MONTH(C$3)>$I$1，自定义格式 ;;;
周末高亮：条件格式 =WEEKDAY(C$3,2)>5
出勤统计：=NETWORKDAYS(开始,结束,节假日列)-SUM(请假列)
```

### 核心方法论：辅助表设计思维

将原始数据（请假记录）与展示界面（考勤表）分离。辅助表集中存储，展示表通过公式动态联动。这是构建任何动态报表的基础。

## WPS 文字表格操作（Writer 内嵌表格）

> 很多人不知道 WPS 文字里的表格也能做计算。

### 公式语法

| 函数 | 语法 | 用途 |
|------|------|------|
| SUM | `=SUM(LEFT)` / `=SUM(ABOVE)` | 向左/向上求和 |
| AVERAGE | `=AVERAGE(ABOVE)` | 向上求平均 |

- **单元格引用**：列 A B C D...，行 1 2 3 4...（类似 Excel 但仅在 Writer 表格内）
- **方向关键词**：`LEFT`（左侧）、`RIGHT`（右侧）、`ABOVE`（上方）、`BELOW`（下方）——WPS 文字表格特有

### 关键陷阱

- **F9 刷新陷阱**：复制含公式的单元格后，值**不自动更新**。必须全选 → `F9` 刷新域代码。否则所有行显示同一个值。
- **Alt+F9 切换域代码**：显示/隐藏底层的 `{ =SUM(B2:D2) }` 语法，用于调试和手动编辑。
- **局限性**：无 PRODUCT 函数，要乘法只能手动编辑域代码（改单元格引用），行多了就暴露局限性。复杂计算建议用 WPS 表格而非文字表格。

### 实操技巧

- **自动编号带前缀**：项目符号和编号 → 自定义列表 → 前缀（如 `ZWQ`）→ 自动生成 ZWQ001, ZWQ002... 格式刷双击连续应用。
- **隐藏表格做对齐（表单填空线）**：插入表格 → 输入标签右对齐 → 去掉所有边框 → 仅给填空格加下边框 → 完美对齐。视图 → 表格虚框可看到隐形表格。
- **座位表间距**：表格属性 → 选项 → 允许调整单元格间距 → 设 0.5cm，无需边框即产生视觉分隔。
- **Delete vs Backspace**：选中列按 Backspace 删结构，Delete 只删内容。

## 长文档排版核心经验（来自转录实战）

### 「先通读，再动手」方法论

排版前先通读全文，识别编号层级体系（如：第X部分 → 第X条 → (X) → 一二三四）。这个调查步骤是专业排版师的习惯。

### 编号→样式→大纲→目录「链式」架构

```
设置多级编号 → 每个级别关联对应标题样式 → 标题样式自带大纲级别 → 大纲级别驱动目录生成
```

> 老师的原话：「只需要设置好一个多级编号，它就会关联标题样式，标题样式关联大纲级别」——一次设置，全链联动。

### 企业级案例排版的常见坑

- **手动编号残留**：应用多级编号后，原文手动输入的「第一部分」「第一条」还在。用通配符 `第[一二三四五六七八九十]{1,}部分*^p` 批量定位 → 删除。
- **样式继承 Bug**：某个级别忘记链接标题样式时，WPS 可能自动套用「标题 1」。发现后手动重置为正文。
- **字体偏好**：中文正式文档统一「微软雅黑」。

### 自定义样式最佳实践

- 从零创建（如「无名标题一/二/三」），不要修改内置样式
- 所有标题的「后续段落样式」设为「正文」——保持纯净
- 改样式 = 全局更新，这是「Word 60% 功力」的核心

### 分节符独立页码

封面 → 目录 → 正文，每部分用「下一页分节符」隔开：
- 目录用罗马数字页码（I, II, III）
- 正文从第 1 页重新开始
- 关键：断开各节的「链接到前一条页眉」

> 「学会这个案例，Word 你就学会了 60%。」

## 审阅与修订关键陷阱（来自转录）

### 「接受显示的修订」vs「接受所有修订」

这是最容易误操作的 UI 陷阱：
- **接受所有显示的修订**：只接受当前筛选条件下可见的修订
- **接受所有修订**：接受整个文档的全部修订（不管筛选）

> 两个按钮紧挨在一起，名字只差两个字，误点后果完全不同。

### 按审阅者批量处理工作流

```
筛选审阅者 A → 接受所有显示的修订 → 切换审阅者 B → 拒绝所有显示的修订
```

### 比较文档（无修订标记的灾难恢复）

同事关了修订模式直接改你的文档 → 收到后看不到任何修改痕迹 → **审阅 → 比较 → 选原文档和修订文档** → 自动生成差异报告。

- 比较粒度设为「字词级别」
- 三窗格视图：原文档 | 修订文档 | 比较结果（Ctrl+滚轮缩放到同屏）
- 结果可输出到新文档

## 接单全流程经验（来自PDF）

### 01 接单前准备

**技能边界**：新手从文档格式优化/简单表格入门 → 熟练后拓展PPT定制。

**作品集**：3-5 个高质量样本，按「PPT/文档/表格/虚拟资料」分类；突出「修改前 vs 修改后」对比效果；必须用真实订单（隐去隐私），避免套用网络模板。

**工具储备**：WPS会员（解锁稻壳模板）+ AI 辅助（豆包/ChatGPT 生成大纲）+ 沟通工具（企微/飞书）+ 无版权图片站。

### 02 找单渠道

| 阶段 | 渠道 | 技巧 |
|------|------|------|
| 新手首选 | BOSS直聘（改定位到大城市搜"PPT兼职"）、闲鱼（发布服务+作品对比图）、小红书（发案例+ #WPS兼职 话题） | 低成本试水 |
| 本地资源 | 高校学生（论文排版）、中小企业（商务PPT/报表） | 校友群/企业微信群推广 |
| 进阶 | 猪八戒网、WPS开放平台（ISV认证需企业1年+） | 订单金额高但竞争激烈 |
| 长期 | 老客转介绍（主动告知「介绍朋友有优惠」） | 成本最低、信任度最高 |

> 任何要求「交押金/保证金/培训费」的渠道直接拉黑。

### 03 谈单技巧

**精准提问四要素**：① 用途与受众 ② 交付要求（页数/格式/时间/源文件） ③ 风格偏好 ④ 特殊要求（公式/规范）。

**报价参考（2025年行情）**：

| 品类 | 简单 | 中等 | 复杂 |
|------|------|------|------|
| 文档格式优化 | 20-50元 | 50-100元（论文） | 100-300元（长篇排版） |
| PPT定制 | 50-150元（套模板） | 150-500元（半定制） | 500-2000元（全定制） |
| 表格定制 | 30-80元 | 80-200元 | 200-500元 |
| 虚拟资料 | 5-20元 | 20-50元 | 50-100元 |

**报价原则**：按复杂度+时间成本，不要低报。首次合作可适当优惠换口碑。

### 04 做单流程

```
① 需求确认（文字记录，客户确认）
② 预付定金（30-50%，防跑单）
③ 制作初稿 → 客户反馈 → 修改（限定修改次数，如免费改2次）
④ 交付终稿 + 尾款（先付尾款再发源文件）
⑤ 售后（保存源文件至少30天，做好评引导）
```

### 05 防坑指南

- 不接明显违法/侵权需求
- 不接「先做出来看看」再谈钱的
- 一切需求走文字确认，语音承诺无效
- 不垫付任何费用
- 敏感内容（竞标方案、内部数据）做脱敏处理
