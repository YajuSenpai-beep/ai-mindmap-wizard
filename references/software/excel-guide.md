# Excel 完全指南 — 从入门到接单就业级

> 从 821 个文件（118 笔记 + 126 TXT 转录 + 3 PDF + 188 练习表）提炼。

## 核心理念

Excel 不是工具，是**思维方式**。三原则：
- **参数-数据源-报表 三层架构**：分离输入参数、原始数据和输出报表
- **能用表的就用表（Ctrl+T）**：自动扩展、结构化引用、切片器联动
- **能用批量的不逐个操作**：重复 3 次以上的操作必有批处理方法

## 基础操作

### 核心概念

| 概念 | 说明 |
|------|------|
| 工作簿 vs 工作表 | 工作簿 = Excel 文件（一本书）；工作表 = 页面（Sheet） |
| 单元格地址 | 列字母+行号（如 H7）。名称框显示当前单元格 |
| 最大容量 | 1,048,576 行 × 16,384 列 |
| 文件格式 | `.xlsx`（新版，功能全）vs `.xls`（旧版兼容，切片器等不可用） |

### 数据录入核心陷阱

| 陷阱 | 后果 | 解决 |
|------|------|------|
| 长数字（>15位）直接输入 | 第16位起变0 | 先设文本格式，或前缀 `'` |
| 日期用 `.` 分隔（2023.5.1） | 变文本「假日期」，无法计算 | 用 `-` 或 `/` 分隔 |
| 数字后直接打「元」「kg」 | 变文本，计算报废 | 自定义格式 `0"元"` |
| 文本型数字（绿色三角） | SUM 忽略它 | 数据→分列→完成；或点警告→转为数字 |

### 常用快捷键

**导航**：`Ctrl+方向键` 跳边缘 / `Ctrl+Home/End` / `Ctrl+PageUp/Down` 切工作表 / `F5` 定位
**选择**：`Ctrl+A` / `Ctrl+Shift+方向键` 扩展选区 / `Ctrl+空格` 选整列 / `Shift+空格` 选整行
**编辑**：`Ctrl+Enter` 批量填充 / `Alt+Enter` 格内换行 / `Ctrl+;` 当前日期 / `F4` 重复上一步
**格式**：`Ctrl+1` 格式对话框 / `Ctrl+T` 超级表 / `Ctrl+Shift+L` 筛选 / `Alt+=` 自动求和

完整快捷键参考 [WPS完全指南](wps-guide.md)（95% 通用）。

## 函数速查

### 逻辑函数

| 函数 | 用途 | 示例 |
|------|------|------|
| IF | 条件判断 | `=IF(B2>=60,"及格","不及格")` |
| IFS | 多条件（免嵌套） | `=IFS(F2<180,"D",F2<240,"C",F2<270,"B",F2<=300,"A")` |
| IFERROR | 屏蔽错误 | `=IFERROR(VLOOKUP(...),"")` |

**嵌套 IF 优化**：从最大值往小值判断，前面的条件已排除的区间不需要 AND 再判。

### 查找与引用

| 函数 | 用途 | 关键规则 |
|------|------|---------|
| VLOOKUP | 垂直查找 | 查找值必须在区域**第一列**；精确匹配用 `0`/`FALSE` |
| INDEX+MATCH | 比 VLOOKUP 灵活 | `=INDEX(返回列,MATCH(查什么,查找列,0))`，可从右往左查 |
| XLOOKUP | 新一代查找 | 自带容错参数，支持反向、通配符 |
| OFFSET | 动态引用 | `=OFFSET(起点,行偏移,列偏移,[高],[宽])` |
| INDIRECT | 文本→引用 | 多级下拉菜单核心：`=INDIRECT(单元格)` |

**VLOOKUP 进阶**：
- 动态列号：`=VLOOKUP($C23,$C$5:$I$15,COLUMN(B1),0)` → 右拉自动换列
- 近似匹配阶梯查找（税率/佣金）：`=VLOOKUP(B4,$F$4:$G$6,2,TRUE)` → 查找表必须升序，首行必须为 0
- 数据格式修复：`*1` 文本转数字，`&""` 数字转文本

**一对多查询（数组公式）**：
`{=IFERROR(INDEX(返回列,SMALL(IF(条件列=条件值,ROW(条件列)),ROW(A1))-偏移), "")}`
→ `Ctrl+Shift+Enter` 三键输入

### 统计函数

| 函数 | 用途 | 注意 |
|------|------|------|
| SUM/AVERAGE/MAX/MIN | 基础统计 | — |
| COUNT | 计数**数值**单元格 | 不统计文本 |
| COUNTA | 计数**非空**单元格 | 含文本 |
| COUNTIF/SUMIF | 单条件 | COUNTIF 条件含运算符需括在引号内：`"<80"` |
| COUNTIFS/SUMIFS | 多条件 | **SUMIFS 求和区域在第一位**（与 SUMIF 参数顺序不同） |
| SUMPRODUCT | 多条件数组运算 | `=SUMPRODUCT((条件1)*(条件2)*求和列)` |
| SUBTOTAL | 仅可见单元格 | 9=求和(含隐藏)，109=求和(忽略隐藏) |

**非重复计数（数组公式）**：`{=SUM(1/COUNTIF(区域,区域))}`

### 文本函数

| 函数 | 用途 |
|------|------|
| LEFT/RIGHT/MID | 提取字符。身份证出生日：`=MID(A2,7,8)` |
| FIND | 查找子串位置。`=FIND("@",B5)` |
| LEN/LENB | 字符数/字节数（中文=2字节） |
| TRIM/CLEAN | 去空格/去不可见字符 |
| SUBSTITUTE | 替换文本。去所有空格：`=SUBSTITUTE(A2," ","")` |
| TEXT | 数值转格式化文本。`=TEXT(MID(A2,7,8),"0000-00-00")` |
| CHAR | ASCII→字符。`=CHAR(ROW(A65))` → A-Z 序列 |

### 日期函数

| 函数 | 用途 |
|------|------|
| TODAY/NOW | 当前日期/时间（易变函数，自动刷新） |
| YEAR/MONTH/DAY | 提取年月日 |
| DATE | 组装日期。`=DATE(年,月+1,日)` 做月加减 |
| DATEDIF | 日期差（隐藏函数）。单位："Y"/"M"/"D" |
| WEEKDAY | 星期几。参数 2 = 周一为1 |

### 数学与舍入函数

| 函数 | 用途 | 场景 |
|------|------|------|
| ROUND/ROUNDUP/ROUNDDOWN | 四舍五入/上舍/下舍 | — |
| FLOOR | 向下舍入到倍数 | 加班（不足0.5h舍弃）：`=FLOOR((B2-A2)*24,0.5)` |
| CEILING | 向上舍入到倍数 | 车辆数：`=CEILING(500/30,1)` |
| MOD | 取余 | 奇偶判断：`=MOD(MID(A2,17,1),2)` |
| RAND/RANDBETWEEN | 随机数（易变） | 抽奖后用粘贴为值固化 |

## 数据分析

### 数据透视表

**创建前提三铁律**：(1) 每列有标题 (2) 无空行空列 (3) 汇总值不混入数据区。

**四区模型**：行（分类维度）/ 列（交叉维度）/ 值（聚合数值）/ 筛选（全局过滤）。

**前置动作**：先 `Ctrl+T` 转超级表 → 再插透视表。新增数据后刷新即可自动纳入。

**关键技巧**：
- 双击任意汇总值 → 自动生成该值的明细工作表（钻取）
- 值字段设置 → 值显示方式 → 总计百分比/差异/差异百分比
- 分析 → 选项 → 显示报表筛选页 → 一键为每个筛选值生成独立工作表
- 右击日期 → 组合 → 选年/季/月（多年数据务必含「年」，防跨年合并）

### 条件格式

| 类型 | 用途 |
|------|------|
| 数据条 | 格内横向柱状图（不含总计行） |
| 色阶 | 热力图效果 |
| 图标集 | 红绿灯/箭头（改阈值从「百分比」→「数字」） |
| 公式规则 | 最灵活。`=$B2=$N$1` 整行高亮 |

**公式规则的心法**：想象从选区左上角开始逐个单元格应用公式，`$` 锁什么取决于你要固定什么。

## 图表与可视化

> 从「Excel 数据可视化」专项课程（8 讲）提炼。图表是**讲故事的媒介**，不是数据的容器。

### 数据可视化核心理念

**文不如表，表不如图**。职场竞争力的分水岭：

| 层级 | 做什么 | 价值 |
|------|--------|------|
| A（罗列数据） | 念数字、贴原始表 | 最低 |
| B（基础图表） | 插入默认图表但无重点 | 一般 |
| C（洞察可视化） | 图表+观点+建议+驱动决策 | **最高** |

**完整链路**：呈现数据 → 发现问题 → 分析原因 → 提出解决方案 → 驱动业务决策。

### 图表学习三大难点

1. **图表类型多**：每种图表元素个性化强（柱形系列重叠、条形逆序类别、饼图起始角度），学习成本高
2. **分析维度多**：难以抓住重点，导致图表表达效果不佳
3. **图表质量要求高**：大数据时代需兼具清晰度、质感和问题洞察力

### 图表选型三梯队（从 8 讲提炼）

**第一梯队（优先选择）**：柱形图/条形图、折线图、饼图/环形图、面积图。适用于大多数通用汇报场景，易懂。
**第二梯队（特色场景）**：仪表盘（进度）、地图、树状图、旭日图。展示进度/层级/地理信息。
**第三梯队（吸睛用）**：雷达图、漏斗图、词云图。多维对比/流程分析/文本可视化，吸引注意但不滥用。

### 图表类型速查矩阵

| 数据关系 | 推荐图表 | 说明 |
|---------|---------|------|
| 对比/比较 | 柱形图、条形图 | 类别标签长→条形图 |
| 趋势/变化 | 折线图、面积图 | 数据点稀疏时加标记 |
| 构成/占比 | 饼图、环形图、百分比堆积柱形 | ≤5-7 类 |
| 分布/相关 | 散点图、气泡图 | 多维数据关联 |
| 流程转化 | 漏斗图 | 逐级流失分析 |
| 进度/KPI | 仪表盘、温度计图 | 单一指标视觉化 |
| 双指标不同量级 | 组合图（柱形+折线，次坐标轴） | 例：销售额(柱)+增长率(线) |

### 图表设计四步法（观点驱动）

```
① 定观点：先明确核心诉求（要资源？要表扬？做监控？），这句话决定了选什么图
② 选图表：根据数据关系选类型（对比/趋势/构成/关联→对应图表）
③ 做减法：删默认网格线、多余图例、冗余标签；配色统一
④ 做加法：用文本框写出核心观点和关键论据，图表自己不会说话
```

**铁律**：不看任何说明，别人能在 10 秒内看懂这张图的核心观点吗？

### 图表图片填充技法

**用自定义图标/Logo 填充柱子，替代默认纯色**：

| 步骤 | WPS | Excel |
|------|-----|-------|
| 选中柱子 | 右键→设置数据系列格式 | 同 |
| 填充方式 | 图片或纹理填充→本地文件 | **复选图→选中柱子→Ctrl+V**（更快） |
| 显示模式 | 「层叠」（图标重复堆叠）vs「伸展」（拉伸变形） | 同 |
| 调大小 | 间隙宽度↓=柱子胖=图标大；层叠缩放调整图标密度 | 同 |

**图标资源**：Echo Font（免费矢量图标）、配色网、Office Plus/WPS稻壳。

### 图表模板体系

**一次设计、终身复用**：
```
① 做完一张满意的图表 → 右键→另存为模板（.crtx）
② 新数据→插入→推荐图表→所有图表→模板→选择模板→一键套用
③ 积累：工作中重复3次以上的图表类型，必存模板
```

**关键前提**：新数据的数据结构（列数、系列顺序）必须与模板创建时一致。

### 进阶图表

**仪表盘（完成率仪表）**：
- 本质=圆环图（刻度盘）+ 饼图（指针）组合
- 原理：半圆180°÷N等份→每扇区角度，透明隐藏下半部分
- 动态显示：文本框链接到单元格 `=单元格地址`

**漏斗图（转化分析）**：
- 用途：展示逐级转化率（浏览→加入购物车→提交订单→支付）
- 核心价值：定位流失最大环节，与行业标准对比找优化方向

### 看板 Dashboard 设计与排版

**看板四步法**：
```
① 明确汇报目标：给谁看？要什么决策？
② 理清数据关系：比较/分布/构成/联系 → 决定每个子图表的类型
③ 创建与美化单图：逐张按四步法制作，配色风格统一
④ 整体排版注入灵魂：逻辑布局+总标题+结论+建议
```

**看板设计四原则**（与 PPT 的 CRAP 一致）：
1. **对齐**：Alt 拖动吸附网格，所有图表边缘对齐
2. **亲密性**：共享主题的图表靠近放置，组间留白
3. **重复**：颜色/字体/图标风格全盘统一
4. **对比**：最重要的洞察用最醒目的颜色/字号

### 配色方法论

**三招取色**：
- Excel 无取色器 → QQ 截图 `Ctrl+Alt+A` 取 RGB → 填充→其他颜色→自定义→输入 RGB
- WPS 内置取色器（吸管图标）→ 直接点击参考图
- 搜「花瓣网/站酷」找参考 → 取色复刻

**配色网站**：ColorPix（取色工具）、配色网、Office Plus、EasyCharts 插件。

**模板「白嫖」法**：截图 Office Plus/WPS稻壳付费模板 → 取色器吸配色方案 → 应用到自己的图表。

### 可视化常见误区

| 误区 | 纠正 |
|------|------|
| 盲目追求复杂图表 | 优先第一梯队，让读者秒懂 > 炫技 |
| 凭个人喜好选图表 | 应基于数据关系和业务目标 |
| 默认图表直接汇报 | 必须按四步法优化后才用于汇报 |
| 汇报只列数据无观点 | 图表必须有洞察文字：发现了什么+建议怎么办 |
| 条形图顺序倒置 | 新插入默认与数据源反向，右键坐标轴→勾「逆序类别」 |
| 改整个系列导致同色 | 每组柱子独立设色：第二次点击选中**单个数据点**再改色 |

| # | 场景 | 核心方法 |

### 获客渠道

| 阶段 | 渠道 | 技巧 |
|------|------|------|
| 新手 | 闲鱼（标题含「Excel代做 当天交付」）、QQ/微信群、小红书（发案例+ #Excel接单） | 案例对比图（杂乱vs成品） |

### 谈单三问

① 用途和受众？② 交付要求（格式/时间/源文件）？③ 特殊要求（公式/规范）？

**所有沟通文字留痕，避免语音沟通。**

### 报价与交付

- 常规 24-48h 交付，加急 +30~50%

- 交付后 24-72h 内删除客户源文件
- 文档加隐形水印：`=CELL("filename")`
