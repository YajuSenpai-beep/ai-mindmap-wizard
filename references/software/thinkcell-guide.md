# Think-Cell Chart10 完全指南 — 咨询级图表引擎

> 从 101 个文件提炼。Think-Cell 是 PPT 第三方图表插件，麦肯锡/尼尔森/世界500强制图标准。官宣节省 70% 图表制作时间。

## 核心定位

Think-Cell 解决的是：**用 Excel 图表做不出的、或能做但非常费劲的咨询级图表**。

```
传统 Excel 图表：基础柱/折/饼，做专业图表需要大量手动调整
Think-Cell：蝴蝶图/瀑布图/麦肯图/甘特图...一键生成，Excel↔PPT 数据联动
```

**适用场景**：数据分析师、商业智能、咨询顾问、财务分析、麦肯锡风格汇报。

## 安装验证

安装成功后在 PPT 中 `插入` 选项卡出现 Think-Cell 组；Excel 中 `插入` 和 `公式` 选项卡也出现对应功能。

## 数据关系（核心概念）

### 数据结构法则

Think-Cell 的数据结构 = Excel 数据**转置 + 空行分隔系列**：

```
原始数据（常规）:               Think-Cell 结构（需转换）:
  月份    销量A   销量B              销量A   销量B
  1月     100     200               (空行)
  2月     150     250       →       1月     100     200
  3月     200     300               2月     150     250
                                    3月     200     300
```

**关键规则**：
- 系列名在上方（横排），类别在左侧（竖排）
- 不同系列之间隔一空行
- 有多组类别时每组之间也隔空行

### 数据转换方法论

**最重要的技能不是画图，而是把普通数据转成 Think-Cell 结构**。技巧：
1. 复制原始数据 → 选择性粘贴→转置
2. 在系列之间插入空行
3. 如需分组（如按产品），用序号列排序：`1,2,3 → 复制 → 按序号排 → 自动产生空行间隔`

## 两种数据联动方式

### 方式一：PPT 直接插入（独立数据）

```
PPT 中：插入→Think-Cell→选图表类型→弹出内置 Excel 表格→填入/粘贴数据
```
数据存在 PPT 内部，不与外部文件联动。

### 方式二：Excel → PPT 联动（推荐）

```
① Excel 中选择数据区域（含行列标题）
② Excel 插入→Think-Cell→选图表类型
③ 自动切换到 PPT → 光标变为十字 → 拖拽生成图表
④ 图表底部显示数据源文件路径
```

**三种更新模式**：
| 模式 | 行为 | 适用 |
|------|------|------|
| **自动更新** | Excel 变→图表即时变 | 实时 Dashboard |
| **手动更新（旗子）** | Excel 变→出旗子图标→点更新生效 | 日常汇报（推荐） |
| **还原** | 回到上次更新状态 | 对比前后数据 |

### 方式三：现有图表套用新数据

```
① PPT 中已有 Think-Cell 图表
② Excel 中选中新数据区域
③ Think-Cell 图表菜单→「现有图表到现有图表」→点一下即替换
```

## 操作界面

### 点选菜单（点击图表出现）
- **字体**：8-28 磅，支持局部选中单独调大小
- **线条**：图表边框，日常去掉（无线条）
- **主题**：继承 PPT 母版主题色 → 换主题=批量换所有图表配色
- **样式**：斜体表达/甘特图样式等
- **使用 Excel 填充**：勾选后，Excel 中单元格背景色 = 图表中对应系列色

### 右键菜单（快捷功能）
| 功能 | 效果 |
|------|------|
| **均线（平均值线）** | 加一条可拖拽的参考线，默认显示所有数据平均值 |
| **Y 轴** | 显示/隐藏垂直轴刻度 |
| **网格线** | 添加/移除背景网格 |
| **图例** | 显示/隐藏系列标签 |
| **趋势线** | 加趋势线+显示变化百分比 |
| **差异箭头** | 标注数据间差异百分比，自动计算 |
| **差异层级** | 在柱子上方显示层级差异线 |

## 图表制作

### 蝴蝶图（Butterfly Chart / 瓣儿条形图）

**用途**：左右对称对比两组数据（如出口 vs 内销、男 vs 女）。

**做法**：
```
① 准备数据：两列数值（左/右各一列），按 Think-Cell 结构排列
② 分别插入两个条形图：一个向右，一个向左
③ 去掉多余标签，仅保留中间年份
④ 对齐两图（拖拽→自动红线吸附→完全对齐）
⑤ 调 Y 轴范围一致（拖拽 Y 轴数字，保证两图比例相同）
⑥ Alt+拖拽微调柱子胖瘦
⑦ 加差异箭头标注关键变化
⑧ 中间标签底色改为白色/背景色，隐藏拼接痕迹
```

### 树状分布图（Tree Distribution）

**用途**：展示数值的分解关系（总销售额=单价×数量，利润=总销售额−成本）。

**做法**：
```
① 关键数据结构：每组数据之间用空行分隔
② 利用序号列快速批量排列：1,2,3→复制→排序→自动分组
③ 逐列插入 Think-Cell 条形图（向右）
④ 对齐所有列：Y 轴比例统一（利用红线吸附）
⑤ 柱子宽度按数据层级调整：核心指标宽，辅助指标窄
⑥ 最终效果：多列条形图左右排列，展示数据拆解逻辑
```

### 累计瀑布图（Cumulative Waterfall）

**用途**：展示从初始值经过增减项到达最终值的过程（财务报表标配）。

**关键规则**：
- 正值在上、负值在下
- 累计柱自动计算（起始值+增减=下一柱基底）
- 总计柱显示最终累计结果
- 支持跨零值（正转负/负转正）自动处理

### 百分比图

**用途**：展示各部分占整体百分比及细分。

**做法**：数据准备为百分比数值 → 选择百分比图 → Think-Cell 自动按 100% 比例绘制。

### 大差异数据切割

**用途**：当数据中极值远超其他项时，用断轴/切割表达避免小值被压扁。

**技巧**：
- Think-Cell 自动检测数值差异 → 插入切割标记
- 可手动调整切割位置和比例
- 切割区用锯齿或斜线标记示意

### 分离式堆积柱折组合图

**用途**：一个图表中叠加柱形图+折线图，展示不同量纲的指标。

**做法**：
```
① 插入堆积柱形图 → 导入主数据
② 选中要变折线的系列 → 右键→更改图表类型→折线
③ 调整折线系列到次坐标轴（右侧 Y 轴）
④ 柱形和折线各自独立缩放
```

### 甘特图（Gantt Chart）

**用途**：项目管理时间线。内置在 Think-Cell 中，非 Excel 手绘。

**特点**：
- 自动按日期分布条状
- 支持里程碑（菱形标记）
- 支持依赖箭头（任务关联线）
- 样式→斜体表达=特定甘特图样式

### 麦肯图（Mekko Chart / 面积坡度图）

**用途**：同时展示市场占比+细分结构（咨询公司战略分析标配）。

### XY 散点图 & 气泡图

**用途**：相关性分析、四象限分析、多维数据分布。

### 日程表（Timeline）

**用途**：甘特图姊妹工具，展示关键节点/里程碑的日程路线。

## 主题配色体系

### 与 PPT 母版联动

Think-Cell 图表颜色 ≠ 手动设置，而是 **继承 PPT 幻灯片母版主题色**：

```
视图→幻灯片母版→主题→颜色→自定义颜色
  → 着色1(系列1颜色) / 着色2(系列2颜色) / ... / 着色6
  → 所有 Think-Cell 图表自动应用
```

**实战意义**：一个 PPT 里 50 张图表，换一次主题色全部统一更新。不用逐张调。

### 推荐配色

- **烟蓝色**（专业数据蓝）— 分析报告首选
- **Office 默认** — 日常汇报安全牌
- **自定义主题** — 匹配企业 VI 色

## 快捷键与效率

| 操作 | 方式 |
|------|------|
| 复制图表 | `Ctrl+拖拽`（副本仍链接同一数据源） |
| 柱子微调胖瘦 | `Alt+拖拽` 边框 |
| 撤销 | `Ctrl+Z`（支持多步撤销） |
| 删除图表元素 | 选中→点叉号（✕）；或右键→删除 |
| 对齐吸附 | 拖拽到其他图表边缘→红线自动吸附对齐 |
| 调 Y 轴范围 | 直接拖拽 Y 轴数字（非输入框方式） |

## 常见陷阱

| 陷阱 | 对策 |
|------|------|
| 数据没按 Think-Cell 结构排列 | 先转置+空行，再看 Think-Cell 默认 demo 数据结构反推 |
| 柱子拉宽只能拉整组 | 必须超过一组宽度的间距才能触发拉宽 |
| 两边比例不一致 | 对齐前先调 Y 轴范围一致，用红线吸附确认 |
| Excel→PPT 不自动切换 | 确保光标停在 PPT 目标页，重试或手动 Ctrl+Tab 切换 |
| 删除元素后不知道怎么恢复 | 每个元素有独立删除按钮；右键菜单可重新添加 |
| 主题换了但图表没更新 | 确认图表使用的是默认主题色而非手动覆盖色 |
| Office 365 弹权限窗口 | 公司环境通常不装 365，个人版需点允许操作 |
