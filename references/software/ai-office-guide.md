# AI 办公完全指南 — DeepSeek × Office/WPS/Excel/Word/PPT

> 从 6 门课程、33+ 视频笔记提炼。核心理念：**「出租车司机模型」**——你告诉 AI 目的地，不需要知道路线。

## 核心理念

```
传统办公：记住哪个功能在哪个菜单 → 点击操作
AI 办公：用自然语言描述你想要的结果 → AI 执行
```

关键原则：
- AI 是助理，不是替代。**始终验证输出**
- 「提问的艺术」重于「背诵提示词模板」——与其记模板，不如学会结构化描述
- 清晰、结构化的分步提示词 > 模糊的复杂一次性请求
- 不同任务用不同模型：V3（快速/聊天）、R1（推理/分析）
- 新任务开新会话，避免上下文污染
- **「1+1>2」协同工作流**：用不同 AI 工具的优势组合（DeepSeek 逻辑 + Kimi 排版 + 通义听悟 会议纪要）

### AI 基础认知

| 概念 | 说明 |
|------|------|
| GPT | 生成式预训练转换器——「生成」= 创造新内容，「预训练」= 海量数据学习语言规则 |
| 多模态 | 处理文本+图像+音频+视频——豆包多模态强，DeepSeek 主力在文本 |
| 幻觉 | AI 「一本正经地胡说八道」——编造不存在的文献、数据 |
| 对齐 | AI 输出需要与人类意图和事实保持一致——需要你校验引导 |

### 访问平台（按可靠性排序）

| 平台 | 特点 |
|------|------|
| DeepSeek 官网 | 最纯正，支持 R1+V3，可联网搜索和上传文件 |

### API 三要素

```
① API Key   — 各平台控制台获取，个人独用
② Endpoint URL — API 服务地址
③ Model Name/ID — 模型标识符（注意：火山方舟的 Model 是「推理端点 ID」）
```

## 集成方式：AI 怎么接入 Office

### 方式一：内置 AI（最简单）

**WPS 灵犀**：
- 点击 WPS 图标召唤面板 → 左下角 DeepSeek 开关变蓝
- 覆盖：写作、PPT、数据分析、思维导图、网页摘要

**WPS AI**：
- 双击 `Ctrl` 唤起 → 自然语言 → JS 执行操作
- 覆盖：条件标记、排序、格式、生成演讲稿

### 方式二：Office AI 助手插件（中等复杂度）

- 下载：`office-ai.cn`
- 支持 Word / Excel / WPS / PowerPoint
- 三种模型来源：内置模型（免费、实时文档交互）/ API Key / 本地 Ollama

### 方式三：手动 VBA 配置（最灵活）

**通用前置**：
1. 启用「开发工具」选项卡
2. 宏安全性 → 启用所有宏 + 信任 VBA 项目

**Excel**：录制 1 秒空宏到「个人宏工作簿」→ VBA 编辑器导入模块 → 替换 API Key → 添加按钮到功能区

**Word**：插入模块粘贴 API 调用代码 → 保存为 `.dotm` → 放入 `C:\Users\[用户]\AppData\Roaming\Microsoft\Word\STARTUP\`

**WPS**：需先安装「WPS VBA」插件 → 模板路径为 `Kingsoft\WPS\startup\`

**标准 VBA API 调用模式**：
```vba
Function DeepSeekQuery(prompt As String) As String
    apiUrl = "https://api.deepseek.com/v1/chat/completions"
    ' Build JSON → MSXML2.XMLHTTP → POST → Parse response
    DeepSeekQuery = parsedContent
End Function
```

## Excel：AI 数据分析

### AI vs 传统函数范式

| 任务 | 传统 Excel | AI 自然语言 |
|------|-----------|------------|
| 求和 | `=SUM(range)` | 「算总库存」 |
| 条件统计 | `=COUNTIF+UNIQUE` | 「有多少产品类别」 |
| 条件求和 | `=SUMIF(range, criteria)` | 「按分类统计数量和金额」 |
| 找最大值 | `MAX+VALUE+RIGHT+XLOOKUP` 组合 | 「找最高分学生」 |

### Excel 中 DeepSeek 的核心能力

| 能力 | 示例 |
|------|------|
| **文本处理** | 多语言混合翻译、长文本摘要、ASCII 艺术生成 |
| **数据清洗** | 拆分地址（省/市/区/街道）、去除乱码、提取数字 |
| **数据分析** | 自动解释数据含义、多维度分析框架、情感分析、合同风险评估 |
| **高级操作** | 日期格式转换、文本公式计算、条件筛选排序、链式推理 |
| **空值依赖** | 源单元格为空时仍执行提示词——可用于无数据输入的内容生成 |

### 数据分析看板工作流

```
① 提交原始数据给 DeepSeek → AI 返回 6 维度分析框架
② 选择 2-4 个最相关维度（不要全用）
③ 问 AI：「如何在 Excel 用透视表和图表实现？」
④ 执行：透视表 → 配置行列值 → 日期分组 → 插入图表
⑤ ⚠️ 关键：用实际图表数据交叉验证 AI 的初始结论
```

### 表格结构转换

二维表（类别作为列标题）→ 一维表（可透视）：

```
提示词：「将此表转为 3 列：产品、月份、销售额。每个产品每月占一行。输出表格。」
```

> 这是传统 Power Query「逆透视」操作的 AI 版本。

## Word：AI 写作与排版

### AI 写作最佳实践

- **结构化提示词公式**：角色 + 背景 + 要求（参考 [提示词模板库](../ai-pipeline/prompt-templates.md) 的角色-目标-条件框架）
- **迭代优于一次性**：先生成框架 → 逐段细化 → 润色
- **不要直接复制 AI 输出**：验证事实、检查格式、适配受众

### 文档自动排版（Markdown 桥接法）

```
原始文档
  → DeepSeek：「按标准文档格式排版，输出 Markdown」
  → 保存为 .md 文件（UTF-8）
  → CloudConvert / Pandoc → .docx
  → Word 打开 → 导航窗格显示完整标题层级
```

### Word 中 DeepSeek 集成场景

- 选中文本 → 选择模型（V3 快速 / R1 深度）→ AI 就地处理
- 三大场景：基础问答、文本校对（错别字/语法）、表格数据处理（计算文档内表格的总和/均值/排序）

## PPT：AI 一键生成

### 三种生成路径

| 方法 | 工具链 | 质量 | 费用 |
|------|--------|------|------|
| **方案一** | DeepSeek（内容）→ Kimi（渲染）→ 下载 `.pptx` | 中高 | 免费 |
| **方案二** | DeepSeek（内容）→ 通义千问（PPT 创建） | 中 | 免费 |
| **方案三** | Gamma（一站式） | 最高 | 付费（积分制） |

### 方案一详细流程（最常用）

```
① DeepSeek 生成内容大纲（开启「深度思考」）
   提示词 = 标题 + 目的 + 受众/场景 + 核心内容 + 细节约束

② 粘贴到 Kimi「PPT 助手」→ Kimi 润色分段
③ 选择模板（商务蓝等）→ 一键生成 .pptx
④ 下载后手动调整：修复 Logo 占位、重叠文本框、核验数据
```

### PPT 提示词公式

```
提示词 = 标题 + 目的 + 受众/场景 + 核心内容要点 + 细节约束

示例：
「标题：2025 Q3 工作总结
  目的：向部门经理汇报季度成果和下季规划
  场景：内部季度复盘会
  核心内容：重点项目、成果数据、挑战与解决方案、Q4 目标
  细节：约 800 字，务实风格，数据驱动」
```

### PPT 最佳实践

- **迭代优于一次性**：案例显示需 4+ 轮追问才得到满意内容
- **先生成完整草稿再细化**：不要中途打断
- **大纲视图编辑同步到幻灯片**：但幻灯片直接编辑**不**同步回大纲
- **始终手动验证**：修复 Logo、调整重叠元素、校对数据

## WPS：国产办公 AI 方案

### WPS 灵犀（内置 DeepSeek）

| 功能 | 能力 | 注意 |
|------|------|------|
| 生成 PPT | 上传素材 → AI 大纲 → 确认 → 生成幻灯片 | 大纲驱动编辑 |
| 长文写作 | 论文、报告，可补充数据和参考文献 | 参考文献格式需核验国标 |
| 数据分析 | 统计、部分图表 | 饼图/雷达图可能失败 |
| 读文档 | 上传文件 → AI 总结分析 | **不支持 `.caj` 格式** |
| 思维导图 | 描述主题 → 生成结构化文本 → 复制文本 → WPS 导入 | 需手动转换标记为缩进 |
| 网页摘要 | 输入 URL/主题 → AI 总结 + 来源 | 来源链接可能不可点击 |

### WPS AI

- 双击 `Ctrl` 唤起 → 自然语言 → 转为 JS 代码执行
- 「喂养式提问」：迭代追问优化
- 工作流：唤起 → 输入指令 → 执行 → 评估（保留/撤销）→ 迭代

### WPS 专属注意事项

- WPS 无原生 VBA 编辑器，必须安装「WPS VBA」插件
- Office AI 插件安装后若不显示 → 信任中心启用「所有第三方 COM 加载项」→ 重启
- 模板路径：`AppData\Roaming\Kingsoft\WPS\startup\`（AppData 默认隐藏）

## 思维导图生成（与我们 skill 的衔接）

### DeepSeek → Markdown → XMind

```
① 上传文档（PDF/Word/TXT）到 DeepSeek
② 提示词：「将附件内容整理为思维导图，以 Markdown 格式输出」
③ ⚠️ 必须开启「深度思考」模式
④ 复制 Markdown 代码 → 保存为 .md（UTF-8）
⑤ XMind → 导入 → 选择「Markdown」格式
⑥ 导图自动生成，手动调整布局配色
```

> 这与我们 [文本→导图流程](../ai-pipeline/text-to-mindmap.md) 完全一致。

### WPS 灵犀 → 思维导图

```
① 灵犀面板描述主题 → AI 生成结构化文本（# ## -）
② 复制文本 → 文本编辑器 → 查找替换标记为空格缩进
③ WPS → 插入 → 思维导图 → 导入处理后的文本
```

## 进阶技巧

### 让 AI 自己生成提问模板

与其自己琢磨提示词，不如让 AI 帮你生成：

```
① 「我要做[具体任务]，请生成一个向 AI 提问的完整详细模板」
② 复制模板 → 填充你的具体信息 → 再次提问
③ 获得高质量输出
```

### 政治/敏感性内容处理

直接让 AI 写「我的感想」可能被拒绝。换种问法：
- 「请总结主流媒体关于 XX 的报道精神」
- 「撰写一篇关于 XX 的宣传文稿」
- 「以新闻稿风格概述 XX 事件」

### 会议纪要自动化

| 工具 | 用途 |
|------|------|
| **飞书妙计** | 实时语音转文字 + AI 总结 |
| **通义听悟** | 上传录音 → AI 生成会议纪要、待办、关键词 |

### 避免 AIGC 检测

- AI 生成的论文可能被 AIGC 检测工具识别
- 建议：AI 生成初稿 → 深度改写（调整句式、添加个人见解、补充实际案例）
- 参考文献格式需核验国标（AI 的引用格式常不规范）

### 上传附件 vs 联网搜索

大多数平台**上传附件时自动禁用联网搜索**，反之亦然。需要最新信息时：
```
① 先联网搜索 → 复制结果
② 撤回附件搜索模式 → 粘贴文本 + 上传附件 → 综合分析
```

## 通用陷阱

| 陷阱 | 对策 |
|------|------|
| AI 生成的数据是编造的 | 始终交叉验证，特别是数字和参考文献 |
| 一次给太复杂的提示词 | 拆成 3-5 个简单步骤，链式处理 |
| API Key 共享使用 | 自己到平台申请个人 Key |
| 中英文标点混用导致公式报错 | 公式中**必须**用英文半角引号和括号 |
| 快速拖拽填充触发大量 API 并发 | 分批处理，留间隔 |
| 前期对话上下文污染新任务 | 新任务 = 新会话 |
