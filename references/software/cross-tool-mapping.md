# 工具对照表 — XMind ↔ draw.io ↔ Visio

> 同一个任务，在不同工具中怎么做。

## 工具定位

| 工具 | 定位 | 最适合 | 价格 |
|------|------|--------|------|
| **XMind** | 思维导图 | 知识整理、头脑风暴、读书笔记、演讲大纲 | 免费版可用 / Pro 付费 |
| **draw.io** | 通用图表 | 流程图、ER图、UML、网络图、平面图、甘特图 | 完全免费 |
| **Visio** | 专业图表 | 企业级流程图、工程图、复杂网络拓扑 | 付费（Microsoft 365 含） |

## 功能对照

| 操作 | XMind | draw.io | Visio |
|------|-------|---------|-------|
| **思维导图** | ✅ 原生支持 | ⚠️ 有模板，非核心 | ❌ 不支持 |
| **流程图** | ⚠️ 可用「逻辑图」近似 | ✅ 完整支持 | ✅ 完整支持 |
| **导入 Markdown** | ✅ 文件→导入→Markdown | ✅ 排列→高级→Mermaid | ❌ 不支持 |
| **组织结构图** | ✅ 切换布局即可 | ✅ 有模板 | ✅ 完整支持 |
| **甘特图** | ❌ 不支持 | ✅ 有模板 | ✅ 完整支持 |
| **ER 图** | ❌ 不支持 | ✅ 有模板 | ✅ 完整支持 |
| **UML** | ❌ 不支持 | ✅ 有模板 | ✅ 完整支持 |
| **网络拓扑** | ❌ 不支持 | ✅ 有模板 | ✅ 完整支持 |
| **平面图** | ❌ 不支持 | ✅ 有模板 | ✅ 完整支持 |
| **SVG 导出** | ✅ 支持 | ✅ 支持 | ✅ 支持 |
| **协作编辑** | ✅ 云端版支持 | ✅ Google Drive 集成 | ✅ SharePoint 集成 |

## 推荐工具链

```
思维导图：
  内容构思 → AI 生成 Markdown → XMind 导入 → 美化 → 导出 PNG/PDF

流程图：
  流程梳理 → AI 生成 Mermaid → draw.io 导入 → 微调 → 导出 SVG/PNG

复杂专业图（ER/UML/网络）：
  结构设计 → AI 生成 Mermaid → draw.io 导入 → 详细编辑 → 导出

企业级图表（需要 Office 集成）：
  AI 生成 → Visio 手动绘制或导入 SVG 微调
```

## 从 AI 到各工具的路径

| AI 输出格式 | → XMind | → draw.io | → Visio |
|-------------|---------|-----------|---------|
| **Markdown** | 文件→导入 | ❌ 不直接支持 | ❌ 不直接支持 |
| **Mermaid** | ❌ 不直接支持 | 排列→高级→Mermaid | ❌ 不直接支持 |
| **SVG** | 文件→导入 | 拖入画布 | 拖入画布 |
| **文本/大纲** | 复制粘贴到节点 | 手动输入 | 手动输入 |

> 💡 **最佳实践**：思维导图用 Markdown → XMind；流程图/技术图用 Mermaid → draw.io。SVG 是跨工具的通用交换格式。
