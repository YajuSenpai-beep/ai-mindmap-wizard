# draw.io 操作指南

> 免费、开源的流程图和图表工具。网页版即开即用（app.diagrams.net），也有桌面版。

## 核心操作流程

### 创建图表

1. 打开 draw.io（网页版 https://app.diagrams.net 或桌面版）
2. 选择存储位置（设备/Google Drive/OneDrive）
3. **新建** → 选择模板或空白图
4. 从左侧形状库拖拽图形到画布
5. 双击图形输入文字

### 常用快捷键

| 操作 | 快捷键 |
|------|--------|
| 新建图表 | `Ctrl+N` |
| 保存 | `Ctrl+S` |
| 撤销 | `Ctrl+Z` |
| 重做 | `Ctrl+Y` |
| 全选 | `Ctrl+A` |
| 复制 | `Ctrl+C` / 粘贴 `Ctrl+V` |
| 复制并链接 | `Ctrl+D`（复制选中节点，自动连线） |
| 组合 | `Ctrl+G` |
| 取消组合 | `Ctrl+Shift+G` |
| 放大/缩小 | `Ctrl+滚轮` |
| 适应窗口 | `Ctrl+H` |

### 连接节点

1. 鼠标悬停在节点边缘 → 出现蓝色箭头
2. 拖拽蓝色箭头到目标节点 → 自动连线
3. 选中连线 → 右侧面板调整：线型（直线/曲线/阶梯）、箭头样式、颜色
4. 双击连线添加标签文字

### 美化

- **右侧格式面板**：调整填充色、线条色、字体、圆角、透明度
- **排列 → 自动布局**：自动排列选中节点（树形/圆形/力导向）
- **样式复制**：`Ctrl+Shift+C` 复制样式，`Ctrl+Shift+V` 粘贴样式
- **图层**：底部面板 → 图层 → 管理多图层
- **页面**：底部标签 → 多页面管理

### 导出

- **文件 → 导出** → 选择格式：
  - PNG/JPG/SVG：适合插入文档和网页
  - PDF：适合打印
  - HTML：嵌入网页
  - XML：draw.io 原生格式，方便后续编辑

## 从 Mermaid 导入

draw.io 支持 Mermaid 语法，AI 生成流程图后可直接导入：

1. 菜单 → **排列 → 插入 → 高级 → Mermaid**
2. 粘贴 Mermaid 代码
3. 点击确定 → 流程图自动渲染
4. 可进一步手动调整布局和样式

参考 [Mermaid流程图](../ai-pipeline/mermaid-flowchart.md) 获取 Mermaid 提示词模板。

## 技巧

- **网格对齐**：视图 → 网格 → 对齐到网格，确保元素整齐
- **连接点管理**：选中节点 → 右侧面板 → 连接点 → 自定义连接点位置
- **容器**：用容器（Container）包裹一组相关节点，便于整体移动
- **图层管理**：复杂图表用图层分离不同关注点（如：逻辑层/物理层）
