# PPT 完全指南 — 从入门到接单级

> 从 1085 个文件（237 笔记 + 238 TXT + 11 PDF + 45 练习文件）提炼。PPT 是设计学科，不只是工具操作。

## 设计四原则（CRAP）

| 原则 | 核心 | 实操 |
|------|------|------|
| **对比 Contrast** | 不一样就让它**非常**不一样 | 标题 2-4x 正文字号；重点数据条 2-3x 视觉权重 |
| **重复 Repetition** | 视觉元素贯穿全篇 | 统一色板/字体/标题栏/装饰元素 |
| **对齐 Alignment** | 一切有视觉连接 | 参考线 1.5cm 边距；Alt 吸附网格 |
| **亲密性 Proximity** | 相关内容放一起 | 组间距 > 组内间距 |

## 配色

### 三属性
**色相（Hue）× 纯度（Saturation）× 明度（Brightness）**

### 四种配色方法
| 方法 | 效果 | 场景 |
|------|------|------|
| 单色系 | 干净专业 | 品牌色 |
| 同色系 | 层次丰富 | 数据报告 |
| 邻近色（~30°） | 和谐多变 | 创意提案 |
| 对比色（180°） | 视觉冲击 | 强调重点（≤10%面积） |

### 三色上限法则
**70-20-10 分布**：主色 70% + 辅助色 20% + 强调色 10%。全篇不超过 3 色。

### 三点评色决策
1. **企业 VI**：从 Logo 取色 → 最强品牌关联
2. **内容主题**：科技=蓝/深色，自然=绿，奢华=金/黑
3. **行业惯例**：医疗=蓝绿（冷静），金融=蓝（信任），科技=深色

## 字体

| 场景 | 标题字体 | 正文字体 |
|------|---------|---------|
| 科技/创新 | 细无衬线 | 常规无衬线 |
| 力量/强势 | 粗角无衬线 | 常规无衬线 |
| 中式/文化 | 毛笔书法 | 衬线或无衬线 |
| 商务/正式 | 思源黑体/微软雅黑 | 常规无衬线 |
| 儿童/趣味 | 圆体 | 圆体 |

**铁律**：正文 ≥20pt（再小=太多字）。中文行距 1.3x。**不要用宋体**投影（笔画消失）。

## 页面类型设计模式

### 封面三型
| 类型 | 做法 | 适用 |
|------|------|------|
| **全图型** | 高清图满铺 + 蒙版 + 文字 | 视觉冲击/演讲 |
| **半图型** | 图占 50%，文占 50%（左右/上下） | 平衡专业 |
| **图形型** | 用形状（矩形=稳定，三角=动感，圆=完整） | 无合适图片时 |

**封面三件套**：A.标题下划线 / B.左侧色块 / C.半透明背景块托底。

**图形型封面三维决策**（从 PPT 超神课提炼）：
- **按主题定形状**：科技→细线几何/教育→圆润/商务→矩形稳重
- **按 VI 定颜色**：从企业 Logo 取主色→着色到封面核心图形
- **按行业定风格**：医疗=蓝绿冷静/金融=深蓝信任/科技=深色极简

### 目录页
- **全图型**：背景图 + 半透明遮罩 + 文字
- **半图型**：一侧图一侧文字列表
- **卡片型**：独立透明卡片承载文字

### 过渡页
- **目录型**：显示全目录 + 高亮当前章 → 维持上下文
- **单向型**：只显示当前章节号+标题 → 更具沉浸感

### 内页万能原则
**「固定框架，替换内容」**：在母版中锁定标题栏/边距/内容区 → 每页只换内容。

### 封底
与封面使用相同设计公式（重复原则）。

## 视觉技法

### 蒙版
半透明形状覆盖图片：纯色（40-60%透明度）或渐变（文字区不透明→图片区透明）。

### 布尔运算
| 运算 | 效果 |
|------|------|
| 联合 | 合并所有形状 |
| 组合 | 合并但挖空重叠区 |
| 拆分 | 沿交线分成独立块 |
| 相交 | 仅保留重叠区 |
| 剪除 | 先选减后选（先选为被减数） |

### 编辑顶点（鼠绘）
三种顶点：**平滑点**（曲线连续）/ **直线点**（独立手柄）/ **角点**（各自调整）。

### 全图型设计
**终极好图 = 高清 + 无水印 + 主题相关 + 有文字空间**。搜图三维法：意境化 → 场景化 → 关联化。

### 图文穿插
自由多边形描物体边缘 + 布尔运算剪除文字 → 3D 纵深效果。

### 版面设计 30 技法（全量速查）

> 从「PPT 版式美化」专项课程（30 讲）全覆盖提炼。每技法解决一个具体版面问题。

| # | 技法 | 核心操作 | 适用场景 |
|---|------|---------|---------|
| 1 | **图片通道** | 图片沿对角线或曲线排列，形成视觉通道→引导视线流动 | 产品展示/故事叙述 |
| 2 | **悬线设计** | 用细线悬挂文字/图片，打破四四方方的呆板布局 | 目录页/引言页 |
| 3 | **数字极端** | 关键数字放大到 100pt+，与正文形成极端对比 | 年度数据/里程碑 |
| 4 | **单图变多图** | 一张大图→拆分为多块独立区域，分别承载不同信息 | 多角度产品展示 |
| 5 | **全图型设计** | 高清图满铺全页+蒙版+文字层。搜图要意境化/场景化/关联化 | 封面/演讲型 PPT |
| 6 | **一页一观点** | 每页只传达一个核心信息，内容超载=拆分多页 | 所有内页的万能原则 |
| 7 | **地图参与** | 将数据/信息直接标注在地图相应位置 | 区域业绩/市场分布 |
| 8 | **流程时间线** | 水平/垂直/曲线型时间轴，节点+事件描述 | 项目历程/发展史 |
| 9 | **留白设计** | 有意大面留白—突出孤立元素。留白=呼吸感=高级感 | 封面/金句页/品牌提案 |
| 10 | **中轴线设计** | 核心元素压中轴线，左右对称或不对称但重量平衡 | 标题页/正式场合 |
| 11 | **平衡感设计** | 页面视觉权重（面积×颜色深度×复杂度）左右均衡≈1 | 对比型/双栏内容 |
| 12 | **表格图形化** | 把传统 Excel 风格表格→用色块/图标/进度条替代 | 数据表→汇报页 |
| 13 | **网格线设计** | 用隐性格线划分版面的列/行区域，所有元素对齐吸附 | 多图排版/产品画册 |
| 14 | **跳台设计** | 内容以阶梯状/台阶级差方式排列，建立递进/层次关系 | 流程步骤/层级说明 |
| 15 | **斜线设计** | 用斜分割线替代水平线，打破沉闷→增加动感和张力 | 运动/科技/年轻化 |
| 16 | **团队展示** | 多人物/头像排版：统一裁剪比例+同距+统一样式信息卡 | 团队介绍/组织架构 |
| 17 | **曲线设计** | 用曲线/波浪线路径排布元素，画面柔和流动 | 创意提案/女性/自然主题 |
| 18 | **套图设计** | 多张图使用统一滤镜/色调/裁剪比例 → 视觉统一性 | 产品系列/案例展示 |
| 19 | **图表+图结合** | 抽象图表旁配具象实物图→降低理解成本，增加感染力 | 数据汇报页 |
| 20 | **焦点设计** | 通过颜色/大小/位置/聚光灯效应，让最重要元素成为唯一视觉焦点 | 关键数据强调 |
| 21 | **框线焦点** | 用半透明框/线框围住核心信息区 → 形成视觉围栏 | 重点信息框选 |
| 22 | **聚光焦点** | 在元素背后加发光/放射状半透明圆→模拟聚光灯效果 | 关键指标强调 |
| 23 | **就近原则** | 相关内容物理靠近 + 组间留白 > 组内间距。强化信息分组 | 多板块内容页 |
| 24 | **超大圆环** | 圆环/圆弧切出页面边缘→制造视觉张力+空间感 | 封面/过渡页 |
| 25 | **图片层叠** | 多图以不同旋转角度+不同层叠顺序叠加→立体感和丰富性 | 创意展示/团队风采 |
| 26 | **撕碎感** | 用不规则边缘/撕裂效果打破矩形边界→粗粝/不羁/艺术感 | 创意/叛逆/告别过去主题 |
| 27 | **配色原理** | 主色70%+辅色20%+强调色10%。取色从参考图/VI/行业惯例 | 所有幻灯片 |
| 28 | **彩带设计** | 彩色飘带/丝带曲线贯穿版面→增加流动性和装饰 | 庆典/活动/年会 |
| 29 | **墨迹效果** | 模拟水墨/水彩/油漆笔触边缘，中式/艺术氛围 | 文化/艺术/中式主题 |
| 30 | **图文穿插** | 自由多边形描物体边缘+布尔运算剪除文字→3D纵深 | 高端产品/人物介绍 |

**铁律**：这 30 种技法可组合使用，但单页不超过 3 种——叠加过多=杂乱。

## 动画

### 动画核心理念

动画**服务于内容**。好=柔和（淡入/浮入），坏=浮夸（回旋/弹跳）。

### 平滑动画（Smooth）

「平滑」切换（需 Office 365/2021）→ 自动在两页之间为同名对象创建变形过渡动画。**一个技巧搞定 80% 的专业动画需求**。

### 关键属性

| 属性 | 设置 |
|------|------|
| **平滑结束** | 30-50%（「柔和感」的关键来源） |
| **弹跳结束** | ≤30%（超过=滑稽效果） |
| **持续时间** | 进入 0.5-2s / 微强调 0.25s |
| **延迟** | 多对象依次入场：逐级增加 0.1-0.2s |

### 组合动画

**核心操作**：用「添加动画」叠加效果（直接点击新动画=替换，不是叠加）。

**经典组合**：淡入 + 放大 105%（自动翻转）+ 缩小 = 「柔和的脉冲强调」。

### 转场动画

不要用「随机」切换——同一逻辑层级的内容使用同一种切换效果：

| 内容关系 | 切换效果 |
|---------|---------|
| 并列关系 | 库/立方体/传送带 |
| 递进关系 | 门/缩放/飞机 |
| 特殊含义 | 折断（告别过去）/ 压碎（幻想破灭）/ 翻转（新篇章） |

### 开场动画

震撼开场 = 品牌 Logo/主标题 + 大尺寸 + 中心缩放进入 + 粒子/光效衬底。时长控制在 3-5 秒。

### 动画铁律

- 同级内容 = 同一切换效果（重复原则）
- 先出现重要内容，后出现解释/辅助内容（信息层级）
- 一页内动画不超过 3 种类型——否则干扰信息

### 核心理念
动画**服务于内容**。好=柔和（淡入/浮入），坏=浮夸（回旋/弹跳）。

### 关键属性
- **平滑结束** = 「柔和感」关键 → 设 30-50%
- **弹跳结束** ≤30%（超过=滑稽）
- **持续时间**：进入 0.5-2s / 微强调 0.25s

### 组合动画窍门
淡入 + 放大 105%（自动翻转）+ 缩小 = 「柔和强调」。用「添加动画」叠加，不要直接点击新动画（会替换）。

### 切换效果选型
| 内容关系 | 效果 |
|---------|------|
| 并列 | 库/立方体/传送带 |
| 递进 | 门/缩放/飞机 |
| 特殊 | 折断（告别过去）/ 压碎（幻想破灭）/ 翻转（新篇章） |

**同级内容 = 同一切换效果**。不要用「随机」。

## 效率法则（诺壹乔）

1. **借力打力**：好图做 70% 的工作。封面=全图型，内页=扁平化。
2. **1234 素材管理**：1 风格(扁平化) + 2 字体(微软雅黑+Arial) + 3 配色方案 + 4 图类型(通用封面/人物/行业/场景)
3. **最小模板 7 页**：封面×1 + 目录×1 + 过渡页×1 + 内容页×3 + 封底×1
4. **素材库原则**：只存网上难找的（自有图片、高频急用图）

## 信息处理公式

**文案优化四步**：通读理解 → 按逻辑切段 → 每段提炼核心词 → 统一表达格式（并列结构）

**视觉平衡**：页面平衡 ≈ 文字区权重 / 图片区权重 ≈ 1（权重 = 面积 × 颜色深度 × 复杂度）

**文字设计感** = 大字号差(2-4x) + 粗细对比(粗体vs常规) + 颜色区分

## 实用铁律

- **一页一观点**
- **好色用在刀刃上**：最强色只给最重要信息
- **内容越少越需要设计**
- 正文 ≥20pt | 中文行距 1.3x
- 搜图必先筛「大尺寸」| Pexels/Pixabay 用英文关键词
- **不要用宋体**投影 | 微软雅黑商用需授权 → 用思源系列
- Slide Master vs 普通视图：能误移的元素 = 放错了地方
- **「破」技法**：故意打破一条对齐规则增加活力
- 低角度=威严/宏大，高角度=广阔/包容

## 接单经验

### PPT 服务类型

| 类型 | 客户 | 核心要求 |
|------|------|---------|
| 总结汇报 | 企业内部 | 清晰、数据可视化、品牌一致 |
| 演讲型 | 主讲人 | 最大视觉冲击、极少文字 |
| 培训课件 | 培训师 | 信息清晰、步骤逻辑、可复用 |
| 创意提案 | 广告公司 | 独特视觉、情感共鸣、故事感 |
| 毕业答辩 | 学生 | 学术感、校徽水印、50%+留白、导航栏 |

### 定价因素
设计美学 × 可编辑性 × 内置多样性 × 配套文档（色号/字体清单）

### 应急锦囊
- 字体丢失：嵌入字体 或 OneKey「一键转图」
- 旧版 Office：另存 .ppt 备份
- 长文本：拆分多页 + 提取关键词 + SmartArt 转换
- Word→PPT：复制大纲 → 粘贴到 PPT 大纲视图
